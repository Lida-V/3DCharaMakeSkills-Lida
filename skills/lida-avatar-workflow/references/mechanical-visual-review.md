# 機械検査と、見た目・動きの確認を組み合わせる

[日本語](mechanical-visual-review.md) · [English](en/mechanical-visual-review.md)

**CLIは確認漏れを減らす補助です。機械検査の合格だけで、造形や動作を完成扱いしません。** 原画との一致、自然な変形、保存後と使用先の再現を分けて確かめます。

## 最初に確認範囲を決める

[制作計画](production-plan.md)と[工程のゴール](quality-goals.md)に、入力版、変える部位、保持する特徴、普段見る距離、必要な画角・動作、使用先、提出資料、今回扱わない残件を入れます。既に決まった条件を引き継ぎ、通常の検査ごとに再承認を求めません。

静止画用なら指定の画角・照明と保存後の再現を中心にし、不要な全身可動検査を加えません。局所修正なら対象と依存部品へ範囲を絞ります。必要な動作を勝手に縮めて不具合を検査外にする意味ではありません。

## 四つの確認を分ける

| 確認 | 調べること | 終了条件と限界 |
| --- | --- | --- |
| 機械検査 | ファイル容量、必要な骨・階層・対応、対象メッシュの割当、修正前後の保持など、各CLIが実装している項目 | 対象項目が条件を満たし、警告・未検査を読んだ。骨位置の美しさや自然な変形は別に見る |
| 画像比較 | 原画の特徴、頭身、輪郭、厚み、関節の位置、材質と陰影 | 基準と候補を同条件で比べ、指定距離・画角で目標を満たす。拡大だけで全体の釣合いを判断しない |
| 動作確認 | 曲がる途中の潰れ・伸び・折れ・貫通、関連部品の追従、戻り | 必要な単独・複合動作で目立つ破綻がなく、基準へ戻る。数枚の検査を全時刻の安全へ広げない |
| 保存・使用先 | 保存再読込、書き出しと読み戻し、必要な実行先での表示・制御 | 同じ成果が再現する。制作ソフト内の合格と使用先の合格を分け、未検証は残件にする |

コマンドの終了コード`0`が保証するのは、そのコマンドの定義した処理・検査範囲だけです。`audit`の処理完了も、美術的な合格を表しません。`rig-audit`やアップロード前の容量確認、レポートの読み方は[制作補助ツール](model-tools.md)へ集約しています。

骨名と本数がそろっていても、腕上げで肩が盛り上がる、握ると手の厚みが失われる、膝の途中角度で輪郭が折れるなら、対象の動作は未達です。数値に合わせるために、了承した原画や良い形を変えないでください。どの骨位置・面の流れ・ウェイト・制御が原因かを診断します。

## 実画像と動作で確かめる順序

1. **基準と候補の版をそろえる。** 保存済みモデルを使い、入力ハッシュと対象名を機械レポート・画像・動画へ対応させます。修正して再保存したら、影響する検査と資料を更新します。古い画像は旧版と明記します。
2. **同じ条件で見る。** 基準と候補のカメラ、姿勢、照明、材質をそろえ、必要な正面・横・斜めを比較します。普段の距離で全体の釣合いを見て、問題部だけ拡大します。材質なし・網目は原因調査に使い、実材質でも確認します。
3. **動かす用途では、単独の通常→途中→必要な最大→戻りを見る。** 端の姿勢だけでなく、変形や切替が急になる途中を確認します。必要な複合動作も追加します。肩なら腕と上体、手なら親指を含む握りと手首、膝なら曲げと脚の向きなど、実際に使う組合せを選びます。
4. **依存部品と保存後を確認する。** 服・爪・装飾・影の層など、修正部に対応するものも表示します。診断で隠した部品を戻し、保存再読込後と必要な使用先で確かめます。問題の時刻・画角・部位を残します。

検証画像は実際の保存モデルから取得します。生成画像や模式図は目標・説明資料として使い、修正結果の証拠へ置き換えません。画像の伝え方と保存版の対応は[画像による引継ぎ](visual-handoff.md)、原因を切り分けて再診断する方法は[試行錯誤](trial-and-error.md)を使います。

## 採否と残件を記録する

機械検査の件数減少、骨数、一般的な比率を、美術合格の自動判定へ変換しません。数値が改善しても見た目が悪化した候補は採用せず、根拠となる比較を残します。全体の完成を一つのフラグで表さず、確認ごとに「合格・未達・未確認・対象外（理由）」を記録してください。

```text
入力版/ハッシュ：[基準] → [候補]。変更部：[ ]。保持部：[ ]。
機械：[結果/対象項目/レポート]。未検査：[ ]。
画像：[結果/同条件の画角・距離/画像]。
動作：[結果/単独・途中・最大・戻り/必要な複合/動画時刻]。
保存・使用先：[結果/環境/確認資料]。
採否：[候補・局所採用・全身統合等の範囲]。残件と次の入力版：[ ]。
```

## AIへの短い依頼文

> [入力版]の[対象]を[用途・目標]に合わせて調整してください。最初に機械検査、同条件の画像比較、必要な動作、保存・使用先の確認範囲を計画へ入れてください。[保持条件]を守り、普段の距離と必要な拡大、通常→途中→最大→戻りと[複合動作]を、関連部品も含めて確認してください。機械検査が通っても不自然なら未達とし、保存版に対応する実画像・動画、確認できた範囲と残件を分けて報告してください。
