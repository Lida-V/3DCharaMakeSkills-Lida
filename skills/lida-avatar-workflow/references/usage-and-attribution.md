# 利用区分と、公開物に残す出典

## 商用利用について

本パックは商用・非商用を問わず利用できます。モデル販売・受託制作、商用の画像・動画、商用アプリや新Skillsへの組込みも制限しません。以下の出典保持条件は商用・非商用で共通です。生成サービス、入力素材、第三者モデル等の利用条件は別途確認してください。

## モデルを制作する場合

このスキルを読んで3Dモデル・画像・動画を作るだけなら、その成果物へLidaや本資料のクレジットを表示する必要はありません。使う素材・サービス・モデルの別の条件は確認してください。

## アプリや新Skillsを公開する場合

この資料を参考にしたり、文章・図解・AI指示・補助コードを組み込んだりしたアプリ／新Skillsを公開する作業では、次の出典を取得者が読める場所へ記載します。アプリならREADME・About・Third-party notices、スキルならREADME・NOTICE等を使います。

> 制作手順・AIへの指示は、Lidaの「3DCharaMakeSkills-Lida」を参考にしています。
> https://github.com/Lida-V/3DCharaMakeSkills-Lida
> 利用・改変箇所：実際に利用した章や変更点を記載してください。

シェーダーも使う場合は、LidaAngelToon / Lida / https://github.com/Lida-V/LidaAngelToon と、実際の利用・改変内容も残します。シェーダーに付く適用ライセンスは別途引き継ぎます。

AIは公開物を作る依頼の中で出典を実際のファイルへ書き、保存先と内容を報告します。依頼文に出典を付けただけで済ませず、既存の著作者表示も消しません。スキルを読んだだけでは他のプロジェクトを書き換えません。

同梱のBlender用 `lida_model_tools.py` は別表記のGPL-3.0-or-laterです。[ツールの適用条件](model-tools.md#利用条件と導入範囲)とGPL本文を保持し、GPLコードへ本資料の独自条件を追加しません。以下の出典追記ツールはGPL本文や完全なコード配布一式を作成する機能ではありません。

## 出典ファイルを作る補助スクリプト

Pythonが使える場合、スキルフォルダ内で実行できます。モデル制作だけなら実行不要です。

```sh
python scripts/ensure_attribution.py --target app --component skills --project-dir <公開物のフォルダ> --changes "素材設計と変形確認の手順を参考にした"
python scripts/ensure_attribution.py --target app --component skills --project-dir <公開物のフォルダ> --check
```

派生スキルは`--target skill`、シェーダーも含める場合は`--component both`を使います。指定先のTHIRD_PARTY_NOTICES.mdへ追記し、既存本文・変更注記を保持、同じ出典を重複追加しません。`--check`は確認のみです。本資料を転載・同梱する場合は、出典に加えて[LICENSE](../LICENSE)も保持してください。

## 利用条件とAIの運用を区別する

正式な許諾は[同梱LICENSE](../LICENSE)、出典の原文は[NOTICE](../NOTICE.md)です。資料の転載・改変・再配布には出典保持条件を適用します。文章等をコピーせず一般的な手法を参考にする場合にも、AIの公開手順では参考元を書きますが、著作権対象外のアイデア・事実まで独占する意味ではありません。利用先全体へこのライセンスを付ける必要もありません。

キャラクター、モデル、受領素材、参考ダンスFBXの利用権を許諾する文書ではありません。自作素材と第三者のものを分け、参考FBX・改名コピー・変換参考モーションを配布パックへ混ぜないでください。
