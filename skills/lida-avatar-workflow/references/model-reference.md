# 完成モデルを制作の参考にする

[日本語](model-reference.md) · [English](en/model-reference.md)

チャイナ和服の新キャラクターの完成例 **r35** を、顔・骨・ウェイト・衣装・材質・表情の関係を学ぶ制作参照用のSkills構成要素として同梱しています。自分の制作では、観察した理由と確認方法を、自分の原画・体型・用途へ合わせて使います。部品のコピー移植や、キャラクターデザインの無断流用を勧める資料ではありません。

## 一緒に取得・配置する

1. [公式Skills 1.9.0の完成配布ZIP](https://github.com/Lida-V/3DCharaMakeSkills-Lida/releases/download/v1.9.0/3DCharaMakeSkills-Lida-1.9.0.zip)を取得し、展開します。参照VRMは約41MBで、このZIPに含まれます。
2. `skills/lida-avatar-workflow`フォルダを、`assets`・`references`・`scripts`・利用条件を含めて丸ごとスキル保存先へコピーします。参照モデルの場所は`assets/model-reference/china-wafuku/ChinaWafuku-Reference-r35.vrm`です。
3. [モデル専用条件](../assets/model-reference/china-wafuku/MODEL-TERMS.md)を確認し、制作で必要な部位だけをVRM対応ソフトの別セッションで観察します。読むだけでモデル処理や環境変更を始めません。

GitHubの **Code → Download ZIP / Source code ZIP** は保守用ソースであり、参照モデル本体は含みません。通常の導入は上記の完成配布ZIPを使ってください。既に導入したモデルだけを再取得する場合は[単独の公式r35配布](https://github.com/Lida-V/3DCharaMakeSkills-Lida/releases/tag/model-reference-r35)も利用できます。

## モデルと資料・コードの条件を分ける

**対象モデル本体の再配布・改変による販売は禁止です。** そのため、モデルを含む公式の一式ZIPを利用者が再配布することはできません。モデルと取り出した素材を除いた文書・図解・コードは、それぞれ従来のLICENSEとGPLの条件に従って利用・配布できます。商用制作の参考として学び、独自に制作した別モデルを販売することを禁止する条件ではありません。

## 見る部位から工程へ戻る

最初に正面・横・斜めの通常形を見て、必要な部位だけを分離します。骨名や数値を写す前に、形・動く場所・重み・隣接部品の対応を確かめてください。

| 見る部位 | 観察すること | 自分の制作へ使う工程 |
| --- | --- | --- |
| 顔・眼球 | 頬と顎の体積、目の位置と回転中心、口内の見える面を同じ向きで確認する | [通常形の調整](adjustment-methods.md)、[眼球](eye-modeling.md) |
| 手指 | 親指の付け根・軸と指間のつながり、単指と握りの途中で変わる厚みを確認する | [手の形・骨・ウェイト](hand-shape.md) |
| 関節 | 肩・肘・膝の骨中心、曲がる帯、ウェイトの切替と輪郭を通常・途中・最大姿勢で対応させる | [メッシュと重み](mesh-weight.md) |
| 袖 | 肘・手首まわりの布の余裕、身体との間隔、腕を曲げた時の折れと貫通を見る | [袖の実践フィードバック](generation-feedback.md)、[修復と補完](mesh-repair-completion.md) |
| マテリアル | 実際の面・UV・画像・材質割当・共有先、透過と輪郭の設定を一組で読む | [材質補正](accessory-materials.md)、[使用先ごとの外観](cross-engine-look.md) |
| 揺れ | 固定する根元、動く骨の列、当たり判定と対象部品を確認し、必要な動作と戻りを再生する | [二次揺れと出力](secondary-motion.md) |
| 表情 | VRMの表情名と実際の変形・材質等への割当を照合し、単独・途中値・組合せで動く部位を確認する | [表情](expression-adjustment.md)、[口型](mouth-shapes.md)、[ウインク](wink-closure.md) |

## VRMから読める範囲

配布VRMは書き出したモデルです。三角面を元の編集用トポロジーや四角面の配置と取り違えず、元ファイルのモディファイア、制御、作業履歴がそのまま残っているとは考えません。取り込みソフトが復元した骨・材質・表情・揺れの設定と、VRM内に保存された情報も区別します。

この参考モデルを取得しただけで、LidaAngelToonへの対応や同じ外観、UEでの表示・動作が保証されるものではありません。必要な使用先では、[機械・画像・動作の判定](mechanical-visual-review.md)と[保存・読み戻し](visual-handoff.md)を別に行います。

AIへは、例えば次のように渡します。

> スキルに同梱された参照用r35のVRMを使い、今回は手指と袖の構造を読み取ってください。通常形と腕・指を曲げた途中を比較し、骨・ウェイト・隣接部品の関係、参考にできる理由、VRMだけでは分からない点を短く報告してください。新規モデルでは自分の原画と用途に合わせて設計するため、作例の数値を既定値にせず、部品移植は行わないでください。

観察結果には入力版、使用ソフト、確認した向き・動作、読み取れた関係、未確認の項目を残します。作例の完成と、今作っているモデルや別の使用先の合格を分けてください。
