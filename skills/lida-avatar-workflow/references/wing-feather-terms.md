# 翼全体の羽の配置と用語

[翼を作る工程](wing-workflow.md) · [図解索引](diagram-index.md)

「長い羽と短い羽」だけで指示すると、生える区域や覆う列を取り違えます。**身体から翼端へ並ぶ風切と、その根元を覆う雨覆（あまおおい）**を分け、下図の番号で原画と対応させてください。

ここは鳥の一般的な構造を創作の参考に整理した資料です。リダの翼の完成図や、創作翼すべての固定仕様ではありません。羽数・形・列数は種類によって違い、図では説明に必要な群を簡略化しています。

## 最初に向きをそろえる

**上面は背側、下面は腹側**です。身体側から翼端側へ進む方向と、前縁（翼の前側）・後縁（風切の先端が作る縁）を示します。画面の上下だけで呼ばず、片翼のどちらの面かも指定してください。

## 図の番号と名前

| 番号 | 名前（英語） | どこにあるか・作る時に見ること |
| --- | --- | --- |
| 1 | 初列風切（しょれつかざきり / primaries） | 手に相当する翼端側に付く風切。翼先の扇、長さの変化、外周のつながりを見る。 |
| 2 | 次列風切（じれつかざきり / secondaries） | 前腕の尺骨に沿う身体寄りの風切。隣同士が重なり、内側の翼面を作る。 |
| 3 | 三列風切（さんれつかざきり / tertials） | 次列の最も身体側を区別する呼び方。明瞭に分かれるかは種類による。三段目や「必ず三枚」ではない。 |
| 4 | 初列雨覆（primary coverts） | 初列風切の根元を覆う群。図は主に初列大雨覆の区域を示し、細かな群は省略。 |
| 5 | 大雨覆（greater coverts） | この図の5は次列大雨覆で、風切の根元にかぶる長めの列。初列側の大雨覆は4に含めて示す。 |
| 6 | 中雨覆（median coverts） | 図では次列側の大雨覆より前縁寄りで、その根元を覆う群。 |
| 7 | 小雨覆（lesser / marginal coverts） | 図ではさらに前縁寄りを覆う小さな羽群。大・中・小は大きさだけで振り分けず、区域と列で見る。 |
| 8 | 小翼羽（しょうよくう / alula） | 前縁の手首付近、第一指（親指）に付く小群。「短い羽すべて」の名前ではない。 |
| 9 | 肩羽（かたばね / scapulars） | 背から肩にある羽群。翼の身体側に重なって見えるが、三列風切や雨覆とは別に扱う。 |
| 10 | 下雨覆（underwing coverts） | 翼下面で風切の根元を覆う群。図は細分を省略してまとめて示す。 |
| 11 | 腋羽（えきう / axillaries） | 身体に近い翼下面の羽群。背側の肩羽と取り違えない。 |

**図の5〜7は次列側の例です。初列側にも大・中・小雨覆があります。** 一般的な鳥体図では初列側の大雨覆を「初列雨覆」、次列側の大雨覆を「大雨覆」と略して示すことがあります。「初列雨覆」と「大・中・小雨覆」を互いに無関係な分類と考えないでください。

## 重なりは別々に確かめる

1. **根元を覆う関係**：図Cのように、短い側の群が後方の群の根元を覆い、風切の取付が露出しない翼面を作る。
2. **同じ列の隣同士**：どちらの羽弁が上か、どこまで露出するかを別に見る。全列が同じ向きに重なるとは限らず、中雨覆は風切や大雨覆と逆になることもある。
3. **上面と下面**：それぞれに覆う羽がある。両面表示の材質を付けただけで、下面の配置まで決まったことにはしない。

隠れる根元と露出する羽先を区別し、開閉の途中でも列が急に裂けないか確認します。取付面・支持体・ウェイトの調整は[翼工程の根元](wing-workflow.md#4-根元の形配置重みを一緒に合わせる)へ進みます。

## 創作翼へ対応させる

まず採用原画へ1〜9の役割を仮に対応させ、採用する群・省略する群・独自の装飾を区別します。リダの原画の「三段」はデザイン上の段数で、三列風切を意味するとは限りません。鳥の一般図へそろえるためだけに、承認済みの輪郭や段数を変えません。

背面・側面・必要な下面へ、同じ番号と「身体側／翼端側」を記します。羽の枚数を決める前に、風切の扇と覆う群の範囲が対応するか確かめてから、[少数の代表羽を作る工程](wing-workflow.md#3-羽種別と列を少数の隣接羽で試す)へ進みます。

> AIへの依頼：採用原画【版】へ、この図の初列・次列相当の風切と、それを覆う群を番号で対応させてください。上面／下面、身体側／翼端側、前縁／後縁を明示してください。三列を三段目、小翼羽を短羽全般として扱わず、創作で省略する群は省略と記してください。まず配置図だけを提示し、採用済みの輪郭・段数を保持してください。
