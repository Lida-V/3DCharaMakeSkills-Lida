# 髪を作る：毛束の形・接続・質感・揺れ

髪は、**全体の輪郭を決める → 少数の毛束で構造を確かめる → 基本追従を作る → UVと質感を整える → 揺れと周囲との動作を確かめる**順に進めます。毛先だけ、艶だけを直し続けず、根元から全長と隣の毛束まで見て判断します。

この章は髪の制作順と具体的な判断をまとめたものです。画像の準備は[入力素材](input-materials.md)、陰影・AO・UVの詳しい調整は[調整方法](adjustment-methods.md)、揺れと出力の扱いは[二次揺れ](secondary-motion.md)へ進んでください。

## 始める前のゴールと素材

[品質目標と工程のゴール](quality-goals.md)から、用途・普段の距離・必要なアップ・動作・使用先を引き継ぎます。各段階で、入力版、変える範囲と固定範囲、比較条件、終了条件、提出物と残件を短く記録します。通常の工程ごとに再承認を求める必要はありません。

> 開始例：採用した髪型と顔の見える範囲を保ち、正面・横・背面・斜めで全長、厚み、根元と毛先を整えます。動く用途では首の左右・上下、前屈、腕上げと戻りで、目立つ突出・裂け・伸びと停止後の収まりを確認します。形は無地とワイヤー、質感は同じ光とカメラで比べ、保存再読込までを今回の区切りにします。使用先の未確認項目は別に残します。

用意するものは次の4組です。

- **形の基準**：同じ髪型の正面・横・背面、顔周りと編み込み・結び目の拡大。長さ、分け目、顔に掛かる範囲、根元、前後の重なりを読めるもの。
- **頭と全身**：採用する頭・耳・首、衣装・肩飾り・翼など。髪単体の設計図と、全身に付けた位置確認図を分ける。
- **現在のモデル**：通常形、単位、左右前後、骨と基準姿勢、UV・画像・材質。生成モデルなら根元や内側の欠落も調べる。
- **確認用の表示と動作**：無地、ワイヤー、実材質、必要な首・体・腕の入力。動作の入り・途中・保持・戻りと、その後に止める区間を用意する。

髪単体を画像から生成する資料には、**顔・マネキン・鼻や顎の輪郭を表示させません**。顔を消した場所で髪まで切れていないか、隠れていた根元や内側がどう続くかも確認します。頭の図を髪の取付位置の参考に使う場合は、髪単体の生成入力と役割を区別します。

リダの髪資料では「一本に終わる各毛束は一先端、不要な枝分かれなし」を指定しました。これは今回の仕様です。別のデザインで意図された分岐・遊び毛まで禁止せず、目標図でどの束がどこで終わるかを決めます。3方向の髪画像は外観了承まで確認されていますが、後に受領した髪FBXがその画像から生成された対応は未確認です。画像の了承を3Dの成功実績へ広げません。

## 1. 粗い形で全長と顔の見える範囲を決める

**ゴール：細かな筋を付ける前に、全体の髪型と頭への位置が合うこと。**

画像しかない場合は[入力素材の流れ](input-materials.md)に沿ってTripoなどで粗いベース／参考モデルを作り、毛束の意図しない融合や根元の欠落を点検します。既に良い3Dがある場合は再生成せず使います。

前髪・顔沿いの髪・頭頂・編み込み・後ろ髪など、設計上の役割を分けます。すべてを別オブジェクトにする指定ではありません。低密度の面やガイドで、次を同じ角度から比較します。

| 見るところ | 調整するもの |
| --- | --- |
| 顔が見える窓 | 額・目・頬・顎のどこまで髪が掛かるか。顔を覆って頭の配置のずれを隠さない |
| 全体の量と長さ | 頭頂から毛先までの外周、横の厚み、背面の広がり。毛先だけを延ばして中腹を細くしない |
| 根元と束ね位置 | 分け目、編み込み、結び目と長髪のつながり。見かけの束ね位置と動き始める位置を対応させる |
| 周囲との空間 | 胸・肩・背中・衣装・翼との位置関係。髪を隠した全身と、髪を戻した通常の距離を両方見る |

良い既存形があれば保持し、髪全体の再生成を必須にしません。前・横・後ろの長さが合わない土台へ、細分化や描き込みだけを足さないでください。

## 2. 毛束の流れ・断面・根元を整える

**ゴール：根元から先まで流れ、幅と厚み、隣の束との重なりを説明できること。**

![毛束の中心線、幅と厚み、根元の重なりと先端を分けて考える設計模式図](../assets/hair-strand-structure.png)

図は設計用の模式図です。中心線は流れを考えるガイドで、実エッジや骨そのものではありません。描いた本数・断面形・厚さをそのまま使う型紙や、実モデルの成功画像にはしません。

1. **一本の流れを先に通す。** 根元から中腹・先端へ中心線を置き、横・背面でも急な折れや逆向きの曲がりがないか見ます。枝先だけを消す修正で、主房の幅や長さを失わないようにします。
2. **幅と厚みを別に変える。** 中心線に沿う複数の位置で横幅と奥行きを確認し、先端へ滑らかに絞ります。正面の細さが合っても横から板・角柱に見えるなら、断面とその向き、前後のつながりを直します。
3. **断面の回転をつなぐ。** 隣り合う断面が急にねじれたり反転したりしないよう、流れに沿って向きを変えます。単に全頂点を平均化して良い輪郭まで丸めないでください。
4. **根元の覆いと前後順を決める。** どの束が手前で、どの根元が頭頂・編み込み・上の束の下へ入るかを側面でも見ます。外側と内側の面順序が逆なら、法線だけを整えても板状の突出は消えません。
5. **接続の種類を区別する。** 同じ毛束内の意図しない切断は接続を調べます。別々の毛束を重ねる設計では、すべてを溶接せず、根元の被覆と動作中の離れ方を確認します。

この制作の立体的な毛束と、薄い面へ透過画像を貼る髪カードは作り方が違います。すべての髪を閉じた筒にする必要はありません。カードを使う場合は、指定距離の薄さ、裏面の表示、透過と重なりを使用先でも確認します。

Blenderのカーブを使う場合は、[公式のGeometry解説](https://docs.blender.org/manual/ja/latest/modeling/curves/properties/geometry.html)で断面・テーパー・傾きの設定を確認します。断面は開いた形と閉じた形の両方があり、利用環境の版と目的に合わせて選びます。

### 生え際・耳の後ろ・うなじの穴を確認する

実際に面を足す・接続し直す手順と、新規面の属性の確認は[メッシュ修復と補完](mesh-repair-completion.md)を使います。別毛束を重ねる設計まで一律に溶接しないでください。

肌が見えるからといって、耳と首をすべて髪で覆いません。**自然に見せる肌、肌色の頭皮、足りない髪の体積**を分け、真横・斜め後ろ・うつむき・首回しで場所を特定します。色だけの問題なら頭皮側の画像を調整できますが、横から見える隙間や髪の輪郭不足は、画像だけでは埋まりません。

立体が必要な所には外側の毛束を保持して内側の髪層を補い、上端を既存の根元の下へ隠します。耳の穴、自然な生え際、襟との余裕を残します。首表面へ密着させた板や、耳の下へ一律に垂らす塊にせず、指定デザインの生え方・流れる向き・浮く量を別々に調整します。リダでは耳たぶの下の肌を残し、耳の後ろからうなじへ流す修正版が採用されました。角度やミリ数を他キャラの初期値にはしません。

## 3. 網目・骨・基本追従を先に確かめる

**ゴール：揺れを止めても、頭と首の動きに対して根元が抜けず、必要な曲がりを表現できること。**

- 毛束の長さ方向へ面をつなぎ、曲がる所を複数の列で支えます。長い一面だけで折らず、曲率と必要な変形に足りる密度を選びます。全髪へ均等に線を増やす必要はありません。
- 固定する前髪・編み込み・結び目と、曲がり始める長髪・結び目下の房を画像へ色分けします。動き始めが結び目から遠いと、上部だけ硬い板に見えることがあります。
- 骨の鎖を流れに沿わせ、各曲げの影響を長さ方向へ滑らかにつなぎます。先に少数の代表毛束で、曲がる位置、伸び、断面の潰れ、隣との裂けを比較します。骨数を増やすだけでは固定域の不一致は直りません。
- 固定とは、決めた親の動きに追従しながら揺れを加えないことです。頭の髪は頭側、首に沿う下地は必要に応じて頭・首の重みを合わせるなど、実際の付着と用途から決めます。すべてを頭100%へ自動的に統一しません。

ウェイトの総和と使用先の影響骨数も確認します。数値検査は[同梱ツール](model-tools.md)、曲がる帯と面の配置は[メッシュと重み](mesh-weight.md)を使い、正規化の成功と自然な変形を別に判断します。

## 4. UV・毛流れ・艶・陰影の役割を分ける

**ゴール：毛束の立体を保ち、使用距離で色・艶・継ぎ目が自然に読めること。**

![基本色、接続、内外の面順序を分けて髪を診断する模式図](../assets/hair-cause-isolation.png)

形のくぼみ・面の突出、法線、輪郭線、画像、AOを一つずつ外して原因を特定します。[具体的な調整方法](adjustment-methods.md)に診断順と局所補正、[AOの調整](adjustment-methods.md#髪のまだらをaoから診断する)に実制作の比較手順をまとめています。

- **立体と描き込みを二重にしない。** メッシュで太い房を分けている所へ同じ強さの太い分割線を重ねると、別の束が増えたように見えます。大きい色の勾配、細い毛流れ、白い艶、奥の暗さを別の役割として調整します。
- **つながる色を部品境界で切らない。** 全体に連続する勾配や艶を作る場合は、部品ごとに独立した高さ・基準を使って四角い色段を作らず、共通の物差しや境界をまたぐ対応でそろえます。
- **艶の最も白い所と消える縁を分ける。** 白さを下端へ集め、下に暗い線を付けると厚い絵の具の滴に見えることがあります。白い芯を内部へ置き、上端・下端・細い先が毛束色へ戻る幅を別々に比べます。形や強さは目標図に合わせ、普段の距離でも艶が消えすぎていないか確認します。
- **UVと画像を一組で保つ。** 毛流れが根元から先へ向き、継ぎ目で反転・段差がないか格子と実材質で見ます。追加した下地を同じ画像へ焼く場合は既存UVとの衝突を調べ、必要時だけ[追加髪の材質・UV・焼き込み先を分ける](adjustment-methods.md#追加した髪のuvと焼き込み)手順を使います。

リダでは細線や艶の修正を繰り返し、下側も柔らかく毛束色へ戻す案が選ばれました。今回の銀白色・淡い藤色・艶の好みは[あとがきのデザイン項目](lida-design.md)へ分け、どの髪にも同じ塗りを強制しません。最終解像度で再確認し、縮小だけで細線や艶が保たれると決めないでください。

## 5. 固定部と揺れ、腕・肩・翼の通り道を確かめる

**ゴール：必要な動作と停止後で、見える突出・裂け・急な跳ねがなく、根元と髪型を保つこと。**

揺れを加える範囲、元へ戻る強さ、揺れを減らす強さ、角度制限、当たり判定は[二次揺れの手順](secondary-motion.md)で一つずつ比較します。髪全体を動かす前に、代表毛束で調整してください。

| 動作 | 主に見るところ |
| --- | --- |
| 首の左右・見上げ・うつむき | 根元と結び目、後ろ髪の背中への倒れ込み、顔沿いの髪と胸・鎖骨 |
| 首かしげ・体の前屈・ひねり | 左右差、肩と飾り、毛先と腰・衣装、隣の毛束の裂けや伸び |
| 腕上げ・頭の後ろへ手を回す | 腕と長髪、袖と固定の編み込み、肩飾り。揺れ髪では直せない固定部も区別する |
| 翼の開閉と身体の組合せ | 髪の全長、根元の覆い、外から見える突出。翼と髪を離しすぎて髪型を変えない |
| 動きの入り・途中・保持・戻り・停止後 | 急な切替、接触相手の変化、揺れ続け、根元のずれ、元の形への戻り |

接触は**どの毛束・骨の鎖が、どの相手へ、どの時刻に入るか**を記録します。腕の当たり判定を全鎖で大きくすると、普段の形から外側の髪まで押されることがあります。問題の鎖だけに範囲を限定し、修正区間と通常形・左右・他の接触相手を再確認します。髪全体の後退や、根元の追従を一律に弱める案で別動作の食い込みを増やさないでください。

VRM 1.0では[SpringBone公式仕様](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_springBone-1.0/README.md)の`springs`ごとに`colliderGroups`を参照します。これは髪の全メッシュ同士の連続した衝突や、Blender独自制御の自動移植を保証する設定ではありません。

リダでは翼と髪の物理反発を設けず、隠れる重なりは許容して目立つ突出を直しました。この方針は個別の制作条件です。別用途では必要な接触・非接触条件を先に定めます。隠れた交差数0を唯一のゴールにせず、必要動作を狭めて未完を隠すこともしません。

停止後の自然な収まりは、動画の最後だけ揺れを0に戻す処理と区別します。代表姿勢の検査は、その間すべての時刻や任意入力の安全を保証しません。問題区間は連続して見て、対象と時間範囲を残してください。

## 6. 保存・合流・使用先を照合する

**ゴール：確認した髪の形・材質・骨・揺れを、最終保存版と使用先へ対応づけられること。**

髪の形、UV・画像・材質、骨の鎖と親、ウェイト、固定範囲、揺れ設定・当たり判定、独自制御、ベイクした動作を一組で渡します。人型と別の髪骨を追加した場合は、人型の骨割当も読み戻して確認し、自動推定だけに任せて誤った骨を混ぜないようにします。

形や網目を変えたら旧い頂点番号のウェイト・法線・AOを無検証で使い回しません。合流した実メッシュと依存先を入力版へ照合し、別名保存して開き直します。手順は[統合と保存版の照合](visual-handoff.md#統合と保存版を照合する)を使ってください。

作業用設定、保存済み設定、スクリプトで再構築する設定、ベイクAction、実際に出力した設定を分けます。髪がBlenderで動いたことを、VRM・Unity・UEでも同じように動く証拠にはしません。使用先で色・透け・骨・根元・揺れ・接触を確認し、未実施の範囲は引継ぎます。

## 繰り返した修正を初回の指示へ入れる

| 起きたこと | 次回の最初に渡す条件 |
| --- | --- |
| 顔を消したら髪が切れ、細い枝が増えた | 髪単体では顔・マネキンなし。根元と内側を連続させ、指定した各毛束を一つの先端までつなぐ |
| 骨を増やしても上部が板のままだった | 結び目と動き始める場所を重ね、固定域からの重みの切替を少数の毛束で確認する |
| メッシュにある束を画像でも太く分割し、艶が滴に見えた | 束の立体・細線・色勾配・艶を別に比較し、白い芯と上下の縁の戻りを分ける |
| 隙間を肌色の変更だけで隠そうとした | 見せる肌・頭皮の色・髪の体積不足を横と斜めで分け、必要部分だけ立体と生え際を補う |
| 接触を避けると髪型や別動作が崩れた | 毛束・鎖・接触相手・時刻を特定して局所調整し、通常形と別の必要動作も再比較する |

これらは制作で観察した失敗と改善です。途中候補の検査合格を初回の採用実績にせず、後から追加された条件を次の依頼へまとめます。同原因の連続2候補で実用上改善しなければ、接続・断面・固定域・当たり判定の構造へ戻って診断します。

## AIへ最初に渡す短い依頼文

> 【用途・距離・動作・使用先】に合わせ、添付の髪型を作成／修正してください。基準の正面・横・背面・斜め、採用した頭と全身、現在モデル、問題画像を渡します。最初に今回の到達状態、変える／固定する範囲、比較条件、終了条件、提出物を示してください。
>
> 粗い形で全長・横の厚み・顔の見える窓・根元と結び目を合わせ、代表毛束の中心線、幅と厚み、断面の向き、隣の束との前後順を確認してください。髪単体資料には顔・マネキンを入れず、顔を消した場所の髪を切らないでください。【一先端にする束】は途中で枝分かれさせず、根元から先まで連続させてください。意図した別々の毛束を全部溶接する必要はありません。
>
> 編み込み・結び目などの固定部と動き始める所を示し、揺れなしの基本追従を先に確認してください。形・接続・法線・画像・AO・輪郭線を切り分け、メッシュと太い描線で束を二重に増やさないでください。艶の芯と上下の縁、全体の色勾配を同条件で比較し、耳裏・うなじは必要な肌を残して不足部分だけ補ってください。
>
> 揺れは代表毛束から調整し、首・体・腕・翼の必要動作を入り→途中→保持→戻り→停止後まで見てください。接触は毛束／鎖・相手・時刻で記録し、局所改善が通常形や別動作を悪化させていないか確認してください。保存版から画像・動画を作り、形・UV・材質・骨・重み・揺れ設定の対応と保持結果を報告してください。局所確認、ユーザー採用、全身合流、出力と使用先の確認、残件を分けてください。

次の工程は[工程索引](process-index.md)、画像の役割と渡し方は[画像付きの引渡し](visual-handoff.md)を使ってください。
