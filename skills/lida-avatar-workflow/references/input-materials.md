# 最初に用意する画像とモデル

[日本語](input-materials.md) · [English](en/input-materials.md)

[工程索引](process-index.md)から、今必要な素材だけを用意してください。画像の枚数より、同じキャラクター・体型・縮尺・姿勢でそろうことが大切です。

画像から新規に制作する基本工程は、Tripoなどの3Dモデル生成サービスでベースモデルや部位別の参考モデルを生成し、Blenderなどで修正する流れを前提としています。基準画像・利用する生成サービス・モデリングソフトは別途用意します。生成後のメッシュ・動き・原画との一致を確認して仕上げます。既存モデルを直すだけなら、新規生成は不要です。

## 用意するもの

![同じ基準から段階別素材と三面図を用意する模式図](../assets/input-alignment-flow.png)

上下の目印と縮尺をそろえ、同じ基準から必要な資料を分けます。身体・服・上着の段階別生成は次回の予防案です。顔の複数角度から三面図への流れは[専用の手順](multiangle-threeview.md)を参照してください。

| 素材 | 分かるようにすること |
| --- | --- |
| 完成デザイン図 | 正面・側面・背面の頭身、衣装の境界、丈、開口、髪と飾りの位置 |
| 素体の図 | 肩・胴・腕・股・脚の形。装飾の少ない密着したベース衣装でもよい |
| 服を着た図 | 同じ素体上の服の輪郭。隠れる袖・裾・背面も補助図で示す |
| 上着を重ねた図 | 上着の開き方、厚み、内側、下の服との重なり |
| 髪あり頭部の図 | 最初から正面・側面・背面を用意。髪型の外周、生え際、頭頂・後頭部の量、耳との重なり |
| 髪なし頭部の図 | 髪あり版と同じ顔・頭蓋・縮尺・表情。頬・顎下・耳と短い首を示し、生成後の顔・頭部の基準にする |
| 髪・部品の図 | 毛束の輪郭と前後関係、根元、厚み、先端。部品ごとに用途を示す |
| 表情シートと単体画像 | 同じ通常顔から必要な口型・普通瞬き・左右ウインク・感情を作る。通常顔の基準セル、本人左右、固定部と画像IDを対応させる |

裸体画像は必須ではありません。服内の身体が動作で見えるか、衣装を外す・差し替えるかを先に決めます。

## 初心者向けの順番

1. 完成像を一つ決め、頭頂・顎・肩・股・膝・足裏などの目印を付ける。
2. 素体を基準に、服、次に上着の図を作る。各段階で体型を変えない。
3. [複数角度から三面図](multiangle-threeview.md)の順で、髪あり/髪なしの同じ頭部を両方用意する。
4. 表情を使う用途では、採用した通常顔から[表情シートと各パターンの単体画像](expression-sheets.md)を生成・比較する。既存資料で足りるものは再生成しない。
5. 頭部の両方を3D生成し、顔・頭部と髪の良い部分を選んで[メッシュ合成](multiangle-threeview.md#3d生成後のメッシュ合成)する。正面・横・背面で通常形と接続を照合する。表情の3D参考は必要な単体画像から用意し、この段階では形の資料として保管する。
6. 新規の動く人型は、通常形と関節の網目を整え、[150MB以内のFBXでTripoのVRM 1.0オートリグ](tripo-autorig.md)を行う。原本と受領結果を照合し、骨・ウェイトと服などの追従を調整する。使える既存リグは再生成しない。
7. 一つの基準顔へ表情の局所キーを作り、表情と必要な首の動きで接続を確かめる。既存キーがある場合は作り直さず、オートリグ往復の保持と動作を照合する。
8. 形と基本の動きが決まってから、精細なUV・色・質感を仕上げる。

素体→服→上着の段階分けは、次回制作の予防案です。リダの制作でこの順序の効果を実測した成功例ではありません。

3Dでは共通の身体一体を基準に、服と上着を修正できる別部品として扱います。着衣モデルから分ける場合も、身体との境界と隠れる部位の欠落を確認してください。

## 髪だけの資料を作るとき

以下は髪単体を生成する入力の条件です。**髪あり頭部の三面図は顔を含む別の入力**として用意し、両者を取り違えないでください。

- 毛束の流れが見える正面・横・背面を、同じ髪型でそろえる。
- 髪単体を入力する用途なら、顔・身体・背景の余分な形を混ぜない。
- 一本に終わる毛束は、先端で枝分かれさせず、幅と厚みを滑らかに絞る。
- 輪郭を確認する図と、色・艶を確認する図の役割を分ける。

毛束の構造・生え際・質感・動作までの順序と具体的な依頼文は、[髪を作る工程](hair-workflow.md)へ進みます。資料を了承したことと、その資料から作った3D形状の確認は別に記録します。

## よく起きるつまずき

正面だけで確定すると、服の背面・内側・肩の厚みが推測になります。全身を別々に生成すると、頭の大きさや顔の前後位置が方向ごとに変わることもあります。

リダの作例では、着衣モデル内の胴体・腕を後から補完しました。通常形で服内へ収めても動作時の露出が残り、接続端とウェイトを合わせる必要がありました。[隠れた身体の補完](skirt-hidden-modeling.md)を参照してください。

画像には用途と版を付け、形の基準・失敗例・未実施の案を区別して渡します。リダ固有の外観は[デザインと好み](lida-design.md)にあります。
