# 最初に用意する画像とモデル

[工程索引](process-index.md)から、今必要な素材だけを用意してください。画像の枚数より、同じキャラクター・体型・縮尺・姿勢でそろうことが大切です。

## 用意するもの

| 素材 | 分かるようにすること |
| --- | --- |
| 完成デザイン図 | 正面・側面・背面の頭身、衣装の境界、丈、開口、髪と飾りの位置 |
| 素体の図 | 肩・胴・腕・股・脚の形。装飾の少ない密着したベース衣装でもよい |
| 服を着た図 | 同じ素体上の服の輪郭。隠れる袖・裾・背面も補助図で示す |
| 上着を重ねた図 | 上着の開き方、厚み、内側、下の服との重なり |
| 頭部の図 | 通常顔、横顔、頬と顎下の立体。髪で輪郭を隠さない補助図 |
| 髪・部品の図 | 毛束の輪郭と前後関係、根元、厚み、先端。部品ごとに用途を示す |

裸体画像は必須ではありません。服内の身体が動作で見えるか、衣装を外す・差し替えるかを先に決めます。

## 初心者向けの順番

1. 完成像を一つ決め、頭頂・顎・肩・股・膝・足裏などの目印を付ける。
2. 素体を基準に、服、次に上着の図を作る。各段階で体型を変えない。
3. 顔の立体が曖昧なら、[複数角度から三面図](multiangle-threeview.md)の順で確認する。
4. 粗い3Dへ進み、正面・横・背面と代表動作で重なりを確かめる。
5. 形と基本の動きが決まってから、精細なUV・色・質感を仕上げる。

素体→服→上着の段階分けは、次回制作の予防案です。リダの制作でこの順序の効果を実測した成功例ではありません。

3Dでは共通の身体一体を基準に、服と上着を修正できる別部品として扱います。着衣モデルから分ける場合も、身体との境界と隠れる部位の欠落を確認してください。

## 髪だけの資料を作るとき

- 毛束の流れが見える正面・横・背面を、同じ髪型でそろえる。
- 髪単体を入力する用途なら、顔・身体・背景の余分な形を混ぜない。
- 一本に終わる毛束は、先端で枝分かれさせず、幅と厚みを滑らかに絞る。
- 輪郭を確認する図と、色・艶を確認する図の役割を分ける。

## よく起きるつまずき

正面だけで確定すると、服の背面・内側・肩の厚みが推測になります。全身を別々に生成すると、頭の大きさや顔の前後位置が方向ごとに変わることもあります。

リダの作例では、着衣モデル内の胴体・腕を後から補完しました。通常形で服内へ収めても動作時の露出が残り、接続端とウェイトを合わせる必要がありました。[隠れた身体の補完](skirt-hidden-modeling.md)を参照してください。

画像には用途と版を付け、形の基準・失敗例・未実施の案を区別して渡します。リダ固有の外観は[デザインと好み](lida-design.md)にあります。
