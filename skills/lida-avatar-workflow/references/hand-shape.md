# 手を作る：基準形・関節・ウェイト・爪

手は、**開いた形を決める → 面と関節を対応させる → 動かして重みを整える → 爪・袖口を合わせる → 保存と使用先で確認する**順に進める。
開いた手にもある段差は形、動かした時だけ出る裂けは重みなど、原因を分ける。細分化や一括スムーズだけで直そうとしない。

この章に、素材・開始ゴール・基準形・網目と関節・重み・爪・短縮・動作・保存・初回依頼文をまとめる。
網目の共通原則は[メッシュとウェイト](mesh-weight.md)、形・骨・法線の切り分けは[調整方法](adjustment-methods.md)へ。手の具体的な確認はこの章へ集約する。

## 工程を始める前に決める

[品質目標とゴールカード](quality-goals.md)を使い、用途・普段の距離・必要な手の動き・使用先を引き継ぐ。静止画だけなら指定姿勢の外観、動くアバターなら必要な動作と使用先の再現までを目標にする。

> 今回は、採用した手の長さ・細さを保ち、開いた手の甲・掌・側面で段差をなくす。動く用途では、握り・指を開く・指さし・つまむと途中動作で、指股と親指側の丸み、爪と袖口を確認する。入力版・変える範囲・固定範囲を示し、同じカメラの無地・ワイヤー・実材質で比較する。保存再読込までを今回の区切りとし、使用先の確認が未実施なら引き継ぐ。

これは開始例。通常の作業ごとに再承認を求めず、決まった用途と品質を使って具体化する。同原因の連続2候補で実用上の見え方が改善しなければ、部位の切り分け・変形方法・骨と網目の対応を再診断する。

## 用意する素材

- **形の資料**：同じ手の甲・掌・親指側の横。必要なら指先側と斜めも加え、手首、指先、指股、爪の位置が分かる画像を用意する。
- **モデル**：採用する通常形、単位、左右・前後・甲側の向き、骨と基準姿勢。修正前を別名で保存する。
- **同条件の表示**：色なしの面、ワイヤー、実際の材質。骨を重ねた図も用意する。光や輪郭線で形が隠れていないか見る。
- **動作**：開く、握る、指一本の曲げ、親指を指先へ向ける動きなど、用途に必要なもの。止めた形だけでなく途中と戻りを含める。
- **依存部品**：爪、袖口、レース、指輪など。手の形・関節表・ウェイト規則・ポーズの版を一組にする。

画像から生成する場合は、指が分離し、指股・親指側・厚みを読める資料を渡す。融合した指、余分な指、爪と肌の混在を先に点検する。細部を増やす前に、基準形として修正できるかを判断する。既存の手が使える場合は再生成を必須にしない。
資料に見えない掌側や厚みは、既存モデルの現状と、目指す形の仮案を分ける。正面絵だけから隠れた形や親指の対向先を決定済みと扱わない。

## 1. 開いた手の基準形を作る

**ゴール：採用したデザインの手を、甲・掌・横で比較でき、手首と指先まで自然につながること。**

![手の甲と掌の向き、指の曲げ帯、母指球と指間から掌へ続く面を読む設計模式図](../assets/hand-structure-map.png)

これは設計と確認箇所を示す自作模式図。実モデルの成功例、解剖学的な寸法表、同じ線数で作るための型紙ではない。実際の骨・網目・必要動作へ対応づけて使う。

| 見るところ | 最初の調整と確認 |
| --- | --- |
| 掌と指の釣合い | 手全体の長さだけでなく、掌の長さ・幅・厚みと各指の節を比較する。掌を縮めた分だけ指の一節を伸ばして帳尻を合わせない |
| 指の付け根 | 指股の谷と、骨が曲がる中心を別の目印にする。付け根の高さを原画と照合し、一直線へ自動的にそろえない |
| 掌と甲の立体 | 掌の起伏、母指球（親指付け根のふくらみ）、甲から指へ下りる面を横と断面で見る。板のような薄さ、深すぎる谷、急な斜面を避ける |
| 親指と人差し指の間 | U字の開き、縁の厚み、そこから人差し指側へつながる丸みを別々に確認する。すき間を広げるだけで接続を直したことにしない |
| 親指と手首 | 採用する基準姿勢で親指の向き・付け根・爪の向きをそろえ、母指球から手首へ滑らかにつなぐ |

数値を使う時は、手首のどの線から、指股・関節中心・指先のどこまでを測るか定義する。隣の指先を拾う測定ミスを防ぐため、測った端点を画像に重ねる。作例の比率・角度・ミリ数を、別のキャラの標準値にしない。

## 2. 網目と関節を対応させる

**ゴール：関節を動かす前に、骨の中心・軸と、縮む面・伸びる面・指間の接続を説明できること。**

1. **関節を図に重ねる。** 人差し指から小指は付け根・中間・指先側、親指は付け根から各節までの中心と軸を記す。画面のしわや一番細い所だけを骨の位置にしない。
2. **指を一周する輪を配置する。** 各関節の前後を複数の輪で支え、長軸方向の辺でつなぐ。中心の一本だけへ折れを集中させない。既存の輪を移して間隔を整え、足りない所だけ追加する。
3. **内外を分けて配分する。** 曲げ内側は列が詰まって反転・鋭い谷にならないか、外側は長い一面だけが伸びず丸みを表せるかを見る。輪の本数と間隔は、厚みと必要な曲げで決める。
4. **指股から掌へ面をつなぐ。** 指の付け根を別々の筒として掌へ刺さず、指間を開閉する面を確保する。母指球は親指と掌の両方へ続く面として扱う。
5. **接続の集中を確認する。** 極、急な密度変化、細長い面、重複・内部面を調べる。強く折れる帯で一点に変形が集まるなら、接続位置や面の流れを見直す。三角面や極があるだけで不合格にはしない。

形が合っている手を一律にリメッシュしたり、全体を細分化したりする必要はない。網目を変えた場合は、頂点番号による古いウェイト・爪・キーの対応を使い回さず再照合する。斜めの輪を試す場合も、骨・面・重みを一緒に比較し、重みだけを斜めに切らない。

人の手では掌に中手骨があり、親指の指節骨は2本、他4指は各3本。基準の確認には[OpenStaxの上肢の骨](https://openstax.org/books/anatomy-and-physiology-2e/pages/8-2-bones-of-the-upper-limb)を使える。ただし、人体の骨の本数だけで創作キャラの比率や最適な網目は決まらない。

VRM 1.0では親指を`ThumbMetacarpal / ThumbProximal / ThumbDistal`、他指を`Proximal / Intermediate / Distal`へ対応させる。親指のHumanoid割当に、他指用の`Intermediate`を使わない。版が違う場合は名前だけでなく骨の役割も[VRM公式仕様](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/humanoid.md)で照合する。補助骨や制御の採否は使用先の条件に従う。

## 3. 親指と指間のウェイトを整える

**ゴール：隣の指と違う動きをしても指股が裂けず、親指を曲げても人差し指側の丸みと母指球が残ること。**

まず、同じ形と骨で重みだけを変える比較を作る。基準形にもある段、骨の中心のずれ、ポーズの不自然さを重みの問題と混ぜない。

- **指一本へ決め打ちしない。** 指股の皮膚を「最も近い指へ100%」と分けると、隣の頂点との割合が急に飛び、指を別々に動かした時に裂けた線が出る。各指の骨に沿う領域を起点に、皮膚のつながりに応じて隣の指・掌へ割合をつなぐ。
- **すき間を越える距離に注意する。** 空間内で近い親指と人差し指を、そのまま同じ領域にしない。制作例では皮膚表面をたどる距離で指の領域を作り、指間の割合を滑らかにした。これは一つの方法で、同じ計算法や幅を全モデルへ強制しない。
- **親指側を広く引っ張りすぎない。** 親指を曲げる時、人差し指の横や甲まで一緒に引かれると、厚さの数値が減っていなくても平たい板に見える。その領域の親指への割合を必要に応じて減らし、手側へ滑らかに戻す。親指自身の皮膚・掌側のU字まで一括で固定しない。
- **母指球の根元を見る。** 手首近くが親指の付け根と強く回ると、親指が手首から生えた筒に見える。骨・ポーズを重ね、手側へ残す割合と親指へついていく範囲を分ける。
- **ポーズも別に診断する。** 親指の付け根だけを大きく倒して指の上へ届かせない。各節の曲げと付け根の寄せ・向き、指と親指を動かす順序を確かめる。自作ポーズの改善を、外部モーションに耐えるメッシュの修正の代用にしない。

変形骨の重みを合計1へ正規化し、使用先の影響骨数の制約を確認する。マスク用グループは混ぜない。[同梱ツール](model-tools.md)は数値確認に使えるが、正規化だけで自然な変形にはならない。

**「規則を保持」と「各頂点の値を保持」は違う。** 座標や関節から計算する規則では、形を変えると値も変わる。規則の差、値の差、骨位置の差を分けて記録する。

## 4. 爪を指先と一組で作る

**ゴール：甲・横・掌側で爪の輪郭が自然に見え、指を曲げても肌から浮いたり爪自体が折れたりしないこと。**

- 爪の幅、根元位置、指先から出る長さ、横の湾曲を別々に調整する。長さだけ先へ足すと、横や掌側からとがって見える場合がある。
- 無地と実材質で、肌とのすき間・食い込み・ちらつき、輪郭線の太さを確認する。爪の形とシェーダーの線によるとがりを分ける。
- 形を保つ硬い爪として作る場合は、指先側の骨へ剛体として追従させる案を使う。制作例では爪全体が対応する末節の骨へ100%追従した。すべての爪表現への必須設定にはしない。
- 手や指の長さを変えたら、爪の位置と骨への対応、UV・模様も同じ版へ合わせる。採用した爪を古い位置の爪で置き換えない。

爪を長くすると、握り・つまむ時の相手の指や掌との接触も変わる。根元の浮き、爪同士の交差、外から見える突き抜けを確認し、隠れた接触が残る場合は範囲と見え方を記録する。静止形だけで合格にしない。

## 5. 短縮や局所補正で段を作らない

**ゴール：採用した長さ・幅・U字を保ち、変更部分から固定部分へ丸みと接線がつながること。**

![手の短縮で詰まる掌の起伏と、U字から人差し指へつなぐ輪郭の模式図](../assets/hand-shortening-flow.png)

図は原因と保持条件を示す模式図で、実モデルの修正前後ではない。掌の高さと内側輪郭は別に診断する。図中の骨位置保持は局所補正の条件で、手の短縮そのものでは、新しい関節位置を先に決め、形・関節・爪を同じ版でそろえる。
小型化そのものでは、移動を許す指先・爪の位置と新しい関節位置を先に定義する。形が決まった後の段差補正で、その端を固定する。小型化と局所補正へ同じ固定条件を一律にかけない。

1. **段のある表示をそろえる。** 開いた形にもあるか、曲げた時だけか、無地でも見えるかを確認する。法線の設定、面の接続、実際の頂点形状を分けて調べる。
2. **短くした方向以外も見る。** 掌の長さだけを縮め、以前の山と谷の高さを残すと、斜面が急になる。厚み・横断面・高さ分布を再評価する。谷を埋める場合も、母指球まで平らに均さない。
3. **隣の領域の移動をつなぐ。** 親指とU字を横へ、人差し指を指の向きへ別々に動かすと、境に段ができる。すき間の向こう側を空間内の近さだけで補間せず、連続する皮膚に沿って変位をつなぐ方法を検討する。
4. **位置と曲がり方を両方つなぐ。** 手首、指先、指定したU字幅、対象外の指・爪を固定する。固定端に座標を合わせるだけでなく、端の隣の面まで接線・曲率を確認する。短い直線で平らにする指示に置き換えない。
5. **点の間隔も戻す。** 曲面をならして点が表面上で滑ると、細い帯に列が詰まり、陰影の筋が残る。固定部と輪郭を守りながら、面に沿う方向の点配置を整え、潰れ・伸び・反転を再確認する。
6. **修正を重ねる前に段階比較する。** 元形 → 短縮のみ → 曲面調整 → 掌補正を同じ向きで比べ、筋が出た段を特定する。輪郭だけの修正で直らない場合は、縮め方から作り直す。

制作例では、約2.7mmの戻りを約7mmに詰めた輪郭を、約20mmの曲線区間でつなぎ直した。局所補正量や戻す距離は手の大きさに依存する作例値であり、そのまま初期値にしない。この輪郭補正だけでは後に見つかった面の筋を解決しきれず、表面に沿う短縮と境界・点間隔の再調整へ進んだ。

## 6. 止めた形と途中動作を確かめる

**ゴール：用途に必要な形とその移り変わりで、新しい裂け・鋭い折れ・目立つ貫通がなく、前の採用条件も保つこと。**

![手の通常形と動作を分け、途中・戻り・指間や親指側の変形を確認する診断模式図](../assets/hand-deformation-check.png)

図は確認方法の模式例。描かれたポーズだけで手全体の合格を保証しない。実モデルの左右・必要な動作へ対応づけ、同じカメラで無地・ワイヤー・実材質を比べる。

| 確認する動作 | 見るところ |
| --- | --- |
| 開いた手・力を抜いた手 | 掌の谷、指付け根の弧、親指側のU字、横の厚み、手首と爪 |
| 指を開く・指一本だけ曲げる | 指股の裂け、隣の指の連れ動き、付け根にできる尖り |
| 付け根・中間・指先側を個別に曲げる | 骨の軸、曲がる位置、内側の潰れ、外側の丸み、爪の折れ・浮き |
| 握る・指さし・チョキ | 親指が手首から折れて見えないか、人差し指側が板にならないか、爪・指が外へ突き抜けないか |
| つまむ・親指を各指へ向ける | 親指の向き、母指球と指間の伸び、相手の指先と爪の接触 |
| 手首を曲げる・反らす＋握る | 手首の接続、袖口・レース・飾りとの干渉 |
| 通常→途中→必要な最大→戻り | 止めた形で隠れた貫通、急な切替、指と親指がぶつかる順序、基準形への復帰 |

用途に合う角度と動作を選び、普段の距離と問題箇所の拡大を両方残す。代表フレームで問題が出た区間は、途中も連続して確認する。自作の握りだけで終えず、動く用途では使用予定のモーションや入力でも確認する。

数値は、辺の長さの変化、面反転、重みの急変、接触の場所と深さなどを画像へ対応づけて使う。接触件数の総和が減っても別の指が悪化する場合がある。意図した接触と突き抜け、見える折れと隠れたしわを分け、必要な可動域を狭めて未達を隠さない。

## 7. 同じ版を保存・統合・出力する

**ゴール：比較した手が最終保存版へ残り、骨・重み・爪・ポーズとの対応を再現できること。**

- 手の形、関節表、骨の基準姿勢、ウェイト規則と計算結果、爪、ポーズ・動作の版を一組で渡す。左右非対称のデザインなら、鏡写しを強制せず指定どおりに比較する。
- 骨の位置が変わった時は、古い骨へ単に結び直して済ませない。新しい関節表で骨・基準姿勢・重みを更新し、依存する袖口や操作リグも再照合する。
- 統合用の手がどの補正を含むかを明記する。新しい版に古い掌補正を二重に加えたり、古い爪を混ぜたりしない。
- 別名で保存して開き直し、同じ姿勢・カメラで確認する。提出画像と動画がどの保存版から作られたかを記録し、再修正した後は必要な比較を更新する。
- 動く用途では、実際に出力したFBX・VRMなどを読み戻し、使用先で指の骨・基準姿勢・動作・爪・材質を確かめる。制作ソフト内の体積保持などがそのまま引き継がれるとは決めない。

局所形状の合格、ユーザー採用、全身への合流、保存後の再現、使用先での合格は別に記録する。実制作で手が局所採用されたことを、すべての指接触や外部モーションの検証済みへ広げない。詳しい保存・出力の確認は[画像の引き渡しと統合](visual-handoff.md)へ。

## 繰り返した修正から得たこと

| 起きたこと | 原因と、次回の初回指示 |
| --- | --- |
| 開いた手はよくても、曲げると指の節が長く見えた | 掌の長さと指の関節位置を別々に評価していた。開いた比率と、関節だけ曲げた節の長さを初期に並べる |
| 指股や親指の付け根に裂けた線が出た | 指の領域を一本へ決め打ちし、境の重みが急変。骨に沿う領域と皮膚のつながりを使って混ぜ、指一本の曲げも見る |
| 親指を曲げると人差し指側が薄い板に見えた | 厚みの減少だけでなく、その面が親指へ引かれていた。形を膨らませる前に、同じ骨・姿勢で重みだけの比較をする |
| 掌を短くすると谷が深くなった | 高さが短い距離へ詰まった。長さ・厚み・高さ分布を一緒に調整する |
| U字の輪郭を直しても、甲や側面に筋が残った | 表面のずれ、固定境界への折れの集中、点間隔の偏りが残った。段階ごとに形とワイヤーを比べ、縮め方から直す |
| 最後のポーズはよくても、途中で親指が指へ入った | 指と親指の移動経路・順序を見ていなかった。握る・開くの往復を動画と問題区間で見る |
| 爪の比較に古い位置のものが混ざった | 試作の描画と最終保存版が違った。手・骨・爪を同版にそろえ、保存版から最終画像を出す |

これらは実制作で観察した原因と改善の記録。初期の局所補正で完了とせず、後続の作り直しと局所採用までを照合してまとめた。図は設計・診断用であり、各手法を使えば初回で成功する保証にはしない。

## AIへ初回から渡す依頼文

> この手を、指定した用途・距離・動作で自然に見える形へ整えてください。基準モデル、甲・掌・側面の資料、無地・ワイヤー・実材質、骨の図と必要な動作を渡します。最初に今回の到達状態、変更／固定範囲、比較条件、終了条件と提出物を短く示してください。
>
> まず開いた形で、掌と指の比率、厚み、付け根の弧、母指球、親指〜U字〜人差し指の連続性を確認してください。形・法線・網目・骨位置・重み・ポーズを分けて診断し、曲がる帯と前後の輪、骨の中心・軸、縮む側と伸びる側を画像へ重ねてください。線数を一律に増やす指示にはしないでください。
>
> 指間を近い指一本へ決め打ちせず、皮膚のつながりに応じて割合をつないでください。親指を曲げても人差し指側の丸みと母指球を保ち、親指自身やU字を一括固定しないでください。短縮が必要なら長さ・厚み・高さ分布も見直し、すき間を越える補間で段を作らず、固定端の接線と点間隔まで確認してください。
>
> 小型化では移動を許す指先・爪位置と新関節を先に決め、その後の段差補正では決まった端を固定してください。この段階で固定すると決めた手首接続、指先、U字幅、対象外の形、爪の意匠を保ち、手の形・関節表・骨・ウェイト規則・爪を同じ版でそろえてください。規則保持と値の再計算を分けて報告し、左右の開閉、指一本の曲げ、握り・チョキ・指さし・つまむ・親指の対向、手首との組合せを、用途に必要な範囲で通常→途中→最大→戻りまで比較してください。
>
> 同条件の画像と動作動画、変更と保持の結果、残件を残し、最終保存版を開き直して確認してください。統合・使用先未検証のものは別の残件とし、局所改善を全身完成とは呼ばないでください。
