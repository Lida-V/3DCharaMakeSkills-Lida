# 最初に制作計画を作り、必要な補正を取りこぼさない

[日本語](production-plan.md) · [English](en/production-plan.md)

制作を依頼されたら、最初に**完成条件・必要な診断と補正・進める順・変更してよい範囲**を一つの計画へまとめます。既にあるモデルも確認し、必要な工程をAIから計画へ入れてください。「次は手を直して」など、同じ制作の個別指示を毎回待つ進め方にしません。

スキルを読むだけでは、環境変更やモデル処理を始めません。実際の制作依頼で許可された対象・範囲に適用します。単一部位の修正依頼なら、その部位と必要な依存部品だけの計画にし、全身の作り直しへ広げません。

[品質の提案と工程ゴール](quality-goals.md) · [工程索引](process-index.md) · [AIへの具体的な依頼](ai-instructions.md)

## 1. 完成条件と、変えてよい範囲をそろえる

| 計画の項目 | 短く書くこと |
| --- | --- |
| 目的・品質 | 何に使い、どの距離で、どこまで見せるか。品質案と推奨理由は[品質目標](quality-goals.md)を使う |
| 基準素材・入力版 | 採用した原画・複数角度・モデル・骨・キー・材質・画像の版。新規頭部は[髪あり/髪なしの三面図と生成後の合成](multiangle-threeview.md)を計画。保護原本と作業コピー |
| 必須の動作・表情 | 使用する動作、左右の視線、瞬き・ウインクなど必要な表情。[表情シートと単体画像](expression-sheets.md)の不足判定・生成・比較と、必要な個別3D参考を計画。静止用途なら指定画角 |
| 使用先・提出物 | 制作ソフト、出力形式、使うアプリ。モデル・比較画像・動画・変更記録の必要範囲 |
| 変更・固定 | 変えてよい部品・面・形・骨・重み・キー・材質・画像と、保持するデザインや対象外 |
| 順番・依存 | 土台の形・関節の網目→新規人型は[FBXでTripoオートリグ](tripo-autorig.md)→骨・網目・基本追従の調整→必要な表情・動作→固まった部位のUV・材質→統合・出力。依存しない作業は並行できる |
| 初期リグの導入 | 新規の動く人型は150MB以内のアップロード用FBXでVRM 1.0骨格を導入。入力/受領版・容量対策・保持照合と、その後のリグ/ウェイト調整を計画。使える既存リグは再利用 |
| 各終了条件 | [機械・画像・動作・保存/使用先](mechanical-visual-review.md)ごとに必要範囲と結果を分ける。同条件の画角・動作・保存後と、今回区切る範囲/残件。CLIの合格だけで完成にしない |

既に決まった用途・品質・原画・保持条件を引き継ぎます。不足が軽微なら仮定を明示し、分かる範囲を進めます。採用済みの意匠や変更許可へ影響する不足は、該当箇所の具体案を示して確認します。

表情シートは「用意してもらうもの」の列挙だけで終えません。初回計画へ、採用通常顔の確定→必要パターンの一覧→不足するシート/単体画像の生成・比較→必要な個別3D参考→局所キーの順を入れます。良い資料や既存キーがあれば使い、生成不要の理由を記録します。下の5項目は構造と補正の診断表として維持し、表情素材の準備状態はこの計画へ別に残します。

## 2. 次の5項目を必ず診断計画へ入れる

各行の状態は **未確認／必要／不要（理由）／保留（理由）／済** のいずれかで記録します。「未確認」は未着手、「保留」は進められない理由と再開条件がある状態です。資料がないことや未検査を「不要」「済」にしません。

全体制作では5項目を実モデルと用途から診断します。部位だけの依頼では5項目の表を残し、関係しない項目に「不要（今回の依頼範囲外）」と明記します。依頼範囲外をモデル全体で検査済みとは扱いません。

| 必須の診断項目 | 最初に調べること | 必要な時に計画へ入れる補正と終了条件 | 詳細 |
| --- | --- | --- | --- |
| メッシュ補正・補完 | 通常形の輪郭・体積・段差・欠け・誤接続、意図した開口、曲がる帯と面の流れ | 原因に合う局所補正・面張り・境界接続・再構築を選ぶ。必要属性を再対応し、固定部と通常形・必要動作・保存後を確認 | [修復・補完](mesh-repair-completion.md)、[網目と重み](mesh-weight.md) |
| 貫通補正 | 問題の部品と相手、姿勢・時刻、通常形か動作中か、見える突出か意図した重なりか | 形・基本追従・キー・揺れのどこが原因か分ける。必要な動作の途中と戻り、関連する部品ペアも比較し、別の場所へ新しい貫通を移さない | [原因の切り分け](adjustment-methods.md)、[衣装と補完](skirt-hidden-modeling.md)、[二次揺れ](secondary-motion.md) |
| マテリアル補正 | 部品→面→実材質データ→画像・UV→ノード・数値→共有先。取り込み・光・露出と材質の原因を分ける | 下記の変更表で範囲を具体化。許可された層だけ補正し、共有先・原画像・形などの保持と保存後・指定使用先を確認 | [装飾の材質補正](accessory-materials.md)、[使用先の外観差](cross-engine-look.md) |
| 手指の動き補正 | 左右の指・親指・指股、骨の中心と軸、重み、爪と袖。開いた形だけでなく必要な握りや入力動作 | 原因に応じて形・網目・骨・重み・ポーズを修正。必要な指別動作・握り・親指の対向と途中・戻り、依存部品を同じ版で確認 | [手の専用工程](hand-shape.md) |
| 眼球モデリング・調整 | 既存の開口・球面・画像・回転中心・固定線、必要な視線・驚き・瞬き・左右ウインク | 既存構造で足りれば保持・局所調整。不足する面や画像だけ補う。目を閉じた形と途中、視線との組合せ、出力後を確認 | [眼球の専用工程](eye-modeling.md)、[まぶたと表情](expression-adjustment.md) |

5項目を必ず直す意味ではありません。必要性を判断し、必要なものを依頼漏れにしないための表です。静止画で指を動かさないなら手指の動作検査を不要にできます。眼球が既に用途を満たすなら再作成は不要です。用途に必要な可動域を減らして「不要」へ変えません。

## 3. マテリアルは、何を変えるかを先に具体化する

「材質補正OK」を、原画の配色・模様・画像や全共有材質の無制限な変更と解釈しません。最初の計画に次の一行を対象ごとに作ります。

| 対象部品・面 | 実材質と共有先 | 変更してよい層・項目 | 固定するもの | 確認が必要な具体案 |
| --- | --- | --- | --- | --- |
| 冠の指定面（例） | 実際に参照する銀材質。腰飾りも共有 | 冠だけの複製材質へ割当し、艶の強さを調整（既に許可された場合） | 配色・元画像・UV・形、腰飾りの材質 | 模様画像の描き直しが必要と判明した場合だけ、その変更範囲と比較案 |

この例の材質分離や変更許可は、すべての依頼に自動適用しません。実際の表には部品と面の範囲、画像参照・UV層、ノードの接続と値、影響する共有先を書きます。同名であることと、同じ材質データを参照することも区別します。

- **範囲が確定している**：既存の指示に従い、診断・許可済み補正・比較・保存確認まで進む。「冠の白飛びを直し、色と模様を保つ」依頼で、冠だけの艶の調整で直せるなら依頼済み範囲として進める。通常の作業ごとに再承認を求めない。
- **範囲が未確定**：原因と、どの色・意匠・画像・共有先が変わるかを同条件の比較案で示す。該当する変更だけ確認し、それまでは元を保つ。
- **他の作業は進められる**：形や指の検査など、未確定の材質変更へ依存しない作業を続ける。制作全体を確認待ちにしない。

材質の実際の調整手順と保持検査は[装飾の材質補正](accessory-materials.md)へ集約します。

## 4. 計画を実行し、未確認のまま終わらせない

1. 入力版と基準の画像をそろえ、5項目を診断する。必要な補正を、対象・原因・変更範囲・依存先と一緒に計画へ入れる。
2. 各工程の前に[ゴールカード](quality-goals.md#各工程の開始時に残すゴールカード)を短く示す。土台や基本追従が未解決なら、その部位の最終UV・材質へ先行しない。書き出しで失う機能は仕上げ前にも小さく試す。
3. 制作依頼の範囲で、必要と判断した診断、許可済みの補正、結果の確認まで進める。「補正が必要です」という報告だけで、同じ範囲の個別指示待ちに戻らない。
4. CLI結果と[画像・動作の判定](mechanical-visual-review.md)を別に残す。数値が改善しても見た目が不自然なら未達とする。同条件の通常→途中→必要な最大→戻りと対象外の保持を確認し、別名で保存して再読込する。使用先は指定された範囲で別に確認する。
5. 次工程の開始条件が満たされ、全体制作の依頼範囲内なら、次の入力版とゴールを記録して引き継ぐ。局所依頼なら、その範囲の結果と残件を渡して区切る。

原本・固定部が変わる、新しい破綻が出る、同原因の連続2候補で使用時の見え方が改善しない場合は、修正を積み増さず[再診断と記録](trial-and-error.md)へ戻ります。局所の改善・ユーザー採用・全身合流・保存・使用先の合格は分けてください。

## AIへの初回指示例

> このSkillsを使い、添付の原画とモデルから【用途】向けに【指定品質】まで制作してください。最初に目的・見る距離・必須動作と表情・使用先・基準素材と入力版・変更可能／固定範囲を整理し、品質案と理由、工程順・依存・各終了条件・提出物を短い制作計画へまとめてください。
>
> 表情が必要なら、通常顔の基準版とパターン一覧を決め、表情シートと単体画像の不足判定・生成・比較を計画してください。資料がないまま個別の追加指示待ちにせず、必要な単体画像だけ3D参考へ進め、一つの顔の局所キーへ使ってください。使える既存資料やキーは再生成しないでください。
>
> メッシュ補正、貫通補正、マテリアル補正、手指の動き補正、眼球モデリング・調整の5項目を必ず診断計画へ入れ、未確認／必要／不要（理由）／保留（理由）／済で管理してください。必要な補正は私から個別に再指示されるのを待たず、今回の制作範囲で診断・許可済み補正・結果確認まで進めてください。全作り直しや眼球の再作成を一律に行わないでください。
>
> 新規の動く人型は、通常形と関節の網目を確認してから150MB以内のFBXをTripoへ渡し、VRM 1.0骨格のオートリグを挟んでください。原本と受領結果の保持を照合し、骨・ウェイト・依存部品の調整へ進めてください。使える既存リグは再生成不要です。
>
> 材質は部品・面・実材質・共有先・画像UV・ノード接続と値まで範囲を具体化してください。既に許可した変更は再承認不要です。未確定の色・意匠・画像・全共有材質の変更が必要なら、具体案と影響を示し、該当変更だけ確認してください。その間も独立した作業を続けてください。
>
> 各工程の到達状態・固定部・比較条件・終了条件を記録し、通常・途中・必要な最大・戻り、保存後と指定使用先を確認してください。次工程の条件が満たされたら依頼範囲内で引き継ぎ、保留理由・再開条件・未確認範囲を残してください。

部位限定の依頼では冒頭を「【部位】だけを【到達状態】まで補正」に替え、対象外の5項目を範囲外と記録します。依頼例自体は、環境変更や外部公開の追加許可を与えるものではありません。
