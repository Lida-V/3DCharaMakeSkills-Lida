# 参照文書

[品質の提案と工程のゴール](quality-goals.md)で初回の完成像と、各工程の区切りを決める。

[工程索引](process-index.md)から必要な方法を読む。数値や本数は作例の条件、候補や模式図は完成モデルの保証とは区別する。

装飾が光りすぎる・曇る・細部が潰れる時は[アクセサリーの材質補正](accessory-materials.md)、欠け・誤接続・不足する体積は[メッシュ修復と補完](mesh-repair-completion.md)へ。原因を選ぶ図と、具体的な手順・保持・検証を一組で使う。

方向・範囲・つながりの確認は[図解索引](diagram-index.md)から必要な図を選ぶ。画像だけで判断せず、実モデルと対応する番号・固定部・確認動作を添える。

材質を整えて別の使用先へ渡す時は、[色管理・陰影・艶・輪郭・透過を切り分ける手順](cross-engine-look.md)を使う。口内と羽の縁の診断、ショット間の基準画像とプリセットもここへ集約している。
