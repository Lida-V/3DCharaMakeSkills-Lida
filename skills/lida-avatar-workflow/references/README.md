# 参照文書

[日本語](README.md) · [English](en/README.md)

新規制作で発生した指のくぼみ・親指の軸・舌と下歯・FBX表示・長袖の折れは、[別制作からの実践フィードバック](generation-feedback.md)へ。症状から診断し、作例の値を既定値へコピーしない。

[制作計画](production-plan.md)を最初に作り、メッシュ・貫通・材質・手指の動き・眼球の診断と必要な補正を工程へ入れる。材質の変更範囲と保留理由も記録し、個別指示の待ち漏れを防ぐ。

[品質の提案と工程のゴール](quality-goals.md)で初回の完成像と、各工程の区切りを決める。

[工程索引](process-index.md)から必要な方法を読む。数値や本数は作例の条件、候補や模式図は完成モデルの保証とは区別する。

新規の動く人型は、通常形と関節の網目を整え、[150MB以内のFBXでTripoのVRM 1.0オートリグ](tripo-autorig.md)を挟む。受領した初期骨格と保持結果を確認してから、骨・網目・ウェイトを調整する。

目・口・感情の参考画像がなければ[表情シートと単体画像を生成](expression-sheets.md)する。初回の素材準備から、必要な個別3D参考、一つの顔への局所キーへつなぐ。

装飾が光りすぎる・曇る・細部が潰れる時は[アクセサリーの材質補正](accessory-materials.md)、欠け・誤接続・不足する体積は[メッシュ修復と補完](mesh-repair-completion.md)へ。原因を選ぶ図と、具体的な手順・保持・検証を一組で使う。

CLIの骨構成・容量・保持確認を、[同条件の画像と動作確認](mechanical-visual-review.md)へつなぎます。機械結果だけで造形合格や完成とは判定しません。

方向・範囲・つながりの確認は[図解索引](diagram-index.md)から必要な図を選ぶ。画像だけで判断せず、実モデルと対応する番号・固定部・確認動作を添える。

通常の瞬きと笑った閉じ目を分ける時は[ウインクの閉じ方](wink-closure.md)へ。目だけの差分と左右を分離し、隣接面・影の層・途中動作を合わせて確認する。

材質を整えて別の使用先へ渡す時は、[色管理・陰影・艶・輪郭・透過を切り分ける手順](cross-engine-look.md)を使う。口内と羽の縁の診断、ショット間の基準画像とプリセットもここへ集約している。
