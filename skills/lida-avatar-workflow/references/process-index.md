# 画像から作るアバターの工程索引

最初は「必要な素材・行う順・つまずき・調整方法」だけを読み、今扱う部位の資料へ進んでください。このパックは制作方法をまとめたもので、元モデルや制作環境は同梱しません。

## 最短の進め方

| 順番 | 行うこと | 読む資料 |
| --- | --- | --- |
| 1 | 完成像、体型、通常顔、使う動作を決める | [入力素材](input-materials.md)、[複数角度から三面図](multiangle-threeview.md) |
| 2 | 身体・服・上着・頭・髪の資料を同じ基準へそろえる | [入力素材](input-materials.md) |
| 3 | 粗い3Dで正面・横・斜めの形を確認する | [調整方法](adjustment-methods.md)、[AIへの指示](ai-instructions.md) |
| 4 | 関節と網目を合わせ、仮の骨とウェイトで早く動かす | [メッシュと重み](mesh-weight.md)、[膝の線の配置](knee-edge-placement.md) |
| 5 | 口・目・手・衣装を、途中動作まで確認して直す | [表情の調整](expression-adjustment.md)、[口型](mouth-shapes.md)、[手の形](hand-shape.md)、[スカートと補完](skirt-hidden-modeling.md) |
| 6 | 変更部位の形と基本追従が固まったら、UV・色・質感を仕上げる | [調整方法](adjustment-methods.md) |
| 7 | 部位を合流し、保存再読込と使用先で確かめる | [画像の引き渡し](visual-handoff.md)、[試行錯誤の残し方](trial-and-error.md) |

書き出し時に失われる仕組みは、仕上げ前にも小さく試します。Blenderでの見え方と、使用先での再現は別々に確認してください。

## 各工程でAIへ渡すもの

- 入力の確定版と、目標の原画・通常形。
- 問題が見える向き・姿勢・拡大画像。
- 変更する部位、固定する形、接続境界、関連する服や飾り。
- 同条件で比較する動作と、終了条件。

「自然に」「丸く」だけで終わらず、どの輪郭・厚み・動きが必要かを画像上で示します。[画像の引き渡し](visual-handoff.md)と[AIへの指示](ai-instructions.md)に依頼文があります。

## 手戻りを減らす確認

1. 通常形にもある段やくぼみを、ウェイトだけで直そうとしない。
2. 点や面の数だけを増やさず、曲がる場所と重みの切り替えを合わせる。
3. 網目を変えたら、表情キー・UV・服・飾りの対応を確認する。
4. 採用した差分と依存部品を合流し、古い骨や爪を混ぜない。
5. 部分の改善、外観の採用、全身統合、使用先の確認を分けて記録する。

図の役割は「目標・問題・設計案・実比較」に分けます。破線の配置案や未達例を、完成済みの構造として使わないでください。

## リダの作例について

作例の寸法・角度・点数は、その体型と用途で試した値です。他のキャラクターへ共通設定としてコピーせず、目印と動作から決め直します。

顔・髪・衣装などの外観上の選択は、[リダのデザインと好み](lida-design.md)へまとめています。技術的な確認方法は各工程を使ってください。
