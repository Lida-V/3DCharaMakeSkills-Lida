# 複数角度の顔から三面図を作る

[日本語](multiangle-threeview.md) · [English](en/multiangle-threeview.md)

[工程索引](process-index.md) · [入力素材](input-materials.md)

三方向を独立して生成する前に、同じ顔を複数角度で確認します。頬・顎・頭蓋の立体を決めてから、同じ縮尺の三面図へ整理します。**最初から髪あり・髪なしの頭部を両方用意し、それぞれの3D生成後に必要なメッシュを組み合わせます。**

## 5つの手順

[素材の関係を示す図](../assets/input-alignment-flow.png)の下段は共通の流れです。頭部は以下の2系統に分け、基準絵と角度別資料の両方を三面図の生成へ渡します。

1. 顔立ちと輪郭の基準になるイラストを一枚決める。
2. 同じ顔の正面・斜め・真横・下からの資料を作る。髪型が分かる版と、髪を除いて頬・顎・頭蓋が見える版をそろえる。
3. 基準絵と角度別資料を両方参照して、**髪あり頭部／髪なし頭部の正面・側面・背面**を同じ縮尺・表情・頭蓋で構成する。髪を除いた時に頭の大きさや顔立ちを作り直さない。
4. それぞれから粗い3Dを生成し、髪なし版の顔・頭蓋と、髪あり版の髪型・根元・頭への収まりを比較する。
5. 採用する顔・頭蓋と必要な髪のメッシュを組み合わせ、正面・斜め・横・背面・下から確認する。通常顔と髪の位置を決めてから表情へ進む。

リダの作例では、斜め45度を補助角度に使いました。角度の種類は、立体が分かりにくい部位に合わせて選んでください。

## 髪あり・髪なしの役割

| 用意する頭部 | 主に確かめるもの・3Dで使う部分 |
| --- | --- |
| 髪あり | 完成髪型の外周、分け目、生え際、頭頂と後頭部の量、耳との重なり。髪と必要な根元の形を使う |
| 髪なし | 顔、頬・顎・頭蓋、耳・短い首のつながり。合成先の顔・頭部の基準にする |

髪あり版は、**顔を含む頭部の生成入力**です。[髪だけの資料](input-materials.md#髪だけの資料を作るとき)で顔やマネキンを出さない条件とは用途が違います。髪なし版も、頭頂から髪を引き算しただけの平らな頭にせず、同じ頭蓋の立体を示します。

## 3D生成後のメッシュ合成

1. 両方を作業コピーで開き、目・鼻・耳・顎・首など共通の目印で縮尺・向き・位置を合わせる。画像がそろっていても生成後の形の一致は別に検査する。髪込みの頭頂を頭蓋の頭頂と取り違えず、良い顔を髪側へ合わせるために変形しない。
2. 髪なし版の良い顔・頭蓋を基準に、髪あり版から髪と必要な根元だけを選ぶ。顔と髪が融合していれば境界を確認し、必要な分離・局所再構築を行う。二つの頭を丸ごと重ねて完了にしない。
3. 不要な二重の顔・頭皮・内部面を整理し、生え際・耳裏・うなじの段差、隙間、頭皮の露出と貫通を確認する。意図して重ねる毛束や別パーツを一括溶接しない。
4. UV・材質・法線、頭/首へのウェイト、既存キーや影の層の対応をそろえる。通常顔・表情・首の動き、髪あり/なしの比較と保存再読込まで確認する。詳細は[修復と属性の再対応](mesh-repair-completion.md#4-新しい面と変形画像の対応をそろえる)、[統合と保存版の照合](visual-handoff.md#統合と保存版を照合する)へ。

ここでの「合成」は、良い部分を選んで同じモデルで使える状態にすることです。オブジェクトを一つに結合したり、すべての境界を溶接したりすること自体をゴールにしません。既に良い頭部と髪がある場合、両方の再生成は不要です。

> 髪あり/髪なしの頭部を同じ基準の三面図から生成してください。髪なし版の採用顔・頭蓋を保持し、髪あり版の必要な髪と根元を選んで組み合わせてください。共通の目印で位置と縮尺を合わせ、二重の頭部・内部面を整理し、生え際・耳裏・うなじの接続を確認してください。UV・材質・法線・ウェイト・表情の対応と、必要動作・保存後の結果を報告してください。

## そろえる目印

- 頭頂・顎・目・鼻・口・耳・首の付け根の高さ。
- 顔幅、頭蓋の前後長、横顔の目鼻口の奥行き。
- 頬のふくらみ、顎下へ回り込む面、顔と頭蓋の比率。
- 表情、口の開き、年齢感、色、縮尺、カメラの透視。

「丸く」は球体にする指示ではありません。基準絵の顔立ちを保ち、どこに厚みと回り込みが必要かを指定します。頭身は、髪込みの高さと頭蓋の大きさを区別して測ります。

## 角度別資料を作る依頼例

```text
添付の基準絵と同じキャラクターを、正面・斜め・真横・下から描いてください。
表情、顔幅、目鼻口の配置、年齢感、色をそろえてください。
髪あり版では採用した髪型と根元を示し、髪なしの補助版では頬・顎下・頭蓋が見えるようにしてください。
両方で同じ頭蓋・顔立ち・目鼻口・耳・首の位置を保ってください。
基準絵の顔立ちを保ち、角度ごとに別の顔へ変えないでください。
```

## 三面図へ整理する依頼例

```text
基準絵と角度別資料を両方参照し、同じ頭部の正面・側面・背面を構成してください。
高さ、縮尺、顔と頭蓋の比率、目鼻口・耳・首の位置をそろえ、透視の差を抑えてください。
頭部単体の3D入力用を、A：採用髪型を付けた頭部、B：同じ頭部から髪を除いた版の2組にしてください。
どちらも不要な飾りを含めず、必要な短い首まで、無地背景にしてください。
髪を除く際も顔・頭蓋の大きさや形を変えず、髪込みの外周と頭蓋の外周を区別してください。
衣装や肩を含む外観資料は、頭部単体の入力と用途を分けてください。
```

これは再利用用の文例です。生成されたイラストは厳密な3D投影ではないため、出力後にも各方向の目印を重ねて確認します。

## 失敗から分かったこと

リダの作例では、顔の丸みが不足し、局所補正を重ねても求める造形に届かず、入力画像から再制作しました。複数角度を先に作って三面図へ整理した後、顔の丸みが改善したとユーザーが評価しました。

丸みや顎の形を明示する指示も併用しており、角度別資料だけの効果を分離した性能試験ではありません。この方法だけで希望する形が保証されるとは扱わないでください。

旧入力・新入力・粗い3Dを対応させて保存し、入力改善と完成モデルの採用を分けて記録します。良い輪郭へ戻れるようにし、改善が届かない場合は[調整方法](adjustment-methods.md)で構造から再診断します。

髪あり頭部も初めに生成し、髪なし頭部と後からメッシュ合成すると頭・髪の崩れが減る、という追加は今回の制作を通したユーザーの知見です。全モデルでの改善率や、この方法だけで破綻がなくなることを保証するものではありません。
