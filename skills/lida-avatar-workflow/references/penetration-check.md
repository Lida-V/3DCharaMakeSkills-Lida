# 貫通を数値で見つけて、直し方を決める

[日本語](penetration-check.md) · [English](en/penetration-check.md)

[工程索引](process-index.md) · [同梱ツール](model-tools.md) · [髪を作る](hair-workflow.md)

**髪・リボン・布などが体や飾りを突き抜けている所を、目で探す前に計算で全部挙げ、所ごとに「削除・切る・押し出す・通し直す」のどれが向くかを出す方法です。** 目で回して探すと、裏側・脇・重なった房の中を見落とします。同梱の [lida_penetration_check.py](../scripts/lida_penetration_check.py) で一覧と寄りの画像を作り、人が見るのは印の付いた所だけにします。

このツールは測定と提案だけを行います。入力の blend は読むだけで、保存しません。直す作業は、提案を見て人と AI が決めてから別に行います。

## 使う場面と、使わない場面

| 状況 | 行うこと |
| --- | --- |
| 生成した髪や布を体へ合わせた直後。どこが突き抜けているか分からない | `check` で一覧を作る |
| 突き抜けた房を、消すか・切るか・動かして直すか決めたい | `advise` で所ごとの提案を出す |
| 直した後に、減ったか・別の所が増えていないか知りたい | 直す前後の `check` を `compare` で比べる |
| 輪や弧の形の飾り（冠・腕輪・首飾り）の食い込みと浮き | [飾りを体・頭へ合わせる](accessory-fit.md)。帯のすき間まで合わせられる |
| 揺れている途中の貫通 | 揺れを焼いたコマを `--frame` で指定して調べる。当たり判定の調整は[二次揺れと出力](secondary-motion.md) |
| 面の欠け・穴・誤接続 | [メッシュ修復と補完](mesh-repair-completion.md) |

## 考え方

### 1　交わる線を計算で出す

調べる部品（髪など）の三角形と、相手（体・飾り）の三角形が交わる線を、そのまま計算します。頂点が中に入っているかだけを見ると、粗い網目では面の途中だけが突き抜けた所を見落とします。交わる線なら、面の途中の突き抜けも必ず線になって出ます。

### 2　見える所と、隠れた所を分ける

交わる線の各部分から、まわり 48 方向へ光線を出します。どの物体にも当たらずに外へ抜ける方向が 2 つ以上あれば「外から見える」と数えます。体の中や重なった房の奥の交わりは「隠れた線」として別に数え、直す対象から外せます。交わった面の数は、見えるかどうかと一致しません。

### 3　近い線をまとめて「箇所」にする

交わる線の端どうしが 8mm より近いものを 1 つの箇所にまとめ、見える線の長い順に番号を付けます。箇所ごとに、いちばんよく見える向きから寄りの画像を描けます。

### 4　閉じた相手には、深さも測る

体・頭・尾のように閉じた相手（`--solid`）には、部品の点から多方向へ光線を出し、面を横切った回数の奇数・偶数の多数決で中か外かを決めます。中の点は、いちばん近い面までの距離を深さにします。ひれ・鎖・薄い板のように開いた相手（`--thin`）は中と外が決まらないので、交わる線だけを調べます。

### 5　意図した重なりは別枠にする

髪の根元が頭に入っているのは不具合ではありません。そういう相手は `--allow` に指定すると、一覧には残りますが、見つかった数と警告からは外れます。別枠にした相手の中の本当の不具合（頭頂の地肌の線など）は数えられないので、そこは目で確かめます。

## 直し方の提案（advise）

`advise` は、部品の面を解析の中だけ細かく分け（モデルは変えません）、閉じた相手の中に埋まった区間を 1 つずつ取り出して、次を測ります。

| 測るもの | 意味 |
| --- | --- |
| 深さ `depth_mm` | 埋まった区間の中で、相手の面からいちばん遠い点までの距離 |
| 埋まった長さ `buried_extent_mm` | 埋まった区間の端から端 |
| 入口の数 `entries` | 1 なら入ったまま出てこない（毛先が埋まっている）。2 以上なら相手の中を通り抜けている |
| 入口の幅 `entry_width_mm` | 房の太さの目安 |
| 入口が見える割合 `visible_entry_percent` | 入口の線のうち、外から見える部分 |
| 島の大きさと、中にある割合 | 部品の中のつながった 1 かたまりが、どれだけ埋まっているか |

その数値から、区間ごとに 1 つの提案を出します。

| 提案 | 出る条件（既定のしきい値） | 行う作業 |
| --- | --- | --- |
| `delete` 削除 | 島がまるごと中にある、または小さな島（40cm² 未満）の 6 割超が中にある | その島を消す |
| `delete_scrap` 小片を削除 | まわりが埋まっていて、1.5cm² 未満だけが外へ出ている | 肌の上に出た小片を消すか、押し込む |
| `trim` 入口で切って閉じる | 入口が 1 つで、35mm より長く埋まっている | 入口で切り、切り口を細く閉じる。外の形は変わらない |
| `pull_tip` 毛先を曲げて出す | 入口が 1 つで、埋まった長さが 35mm 以下 | 毛先の向きを少し変えて外へ出す |
| `push` 押し出す | 深さ 4mm 以下。または深さが入口の幅の 0.6 倍以下かつ 15mm 以下 | その区間をなめらかに外へ動かす |
| `reroute_or_cut` 通し直す／切る | 上のどれでもない（房の太さに対して深い） | 通り道を外へ作り直すか、埋まった区間を切って両端を閉じる。見た目で人が決める |
| `leave` そのまま | 入口の見える割合が 5% 未満 | 何もしない |

- しきい値はすべてオプションです（`--shallow-mm`・`--tip-extent-mm`・`--push-ratio`・`--push-max-mm`・`--hidden-share`・`--small-island-cm2`・`--island-inside-share`・`--scrap-cm2`）。作例の値で、どのモデルにも合う値ではありません。
- 提案は大きさだけで決まります。原画でどの房が大事かは見ていません。`reroute_or_cut` と、見せ場の房の `trim`・`delete` は、人が画像を見て決めます。
- 部品の辺が粗い時（辺の中央値が 10mm を超える）は、報告の `notes` に出ます。`push` で直すなら、その場所だけ先に分割します。
- 肩・脇・股のように姿勢で当たり方が変わる所は、基準の姿勢だけで直し方を決めず、使う姿勢でも調べます。
- 薄い相手（ひれ・鎖）は `advise` の対象外です。`check` の箇所の大きさと画像から決めます。

## 用意するもの

- 保存済みの blend（読むだけ）。開いている制作ファイルを直接は使わず、保存した版か写しを指定する。
- 調べる部品の名前（`--parts`）と、相手の名前（`--solid`・`--thin`）。相手は名前で明示する。
- 新しい報告の JSON の場所。画像も要るなら、新しいフォルダの場所（`--render-dir`）。どちらも既にあると止まる。
- Blender（背景実行）。`compare` と計算部分は通常の Python と numpy だけで動く。

## AI が行う順序

1. 部品と相手、意図した重なり（`--allow`）、調べる姿勢やコマをユーザーの指定と制作記録から決める。
2. `check` を実行し、要約（箇所の数、相手ごとの見える線の長さ）を読む。
3. `advise` を実行し、提案ごとの数と、辺が粗いという注記を読む。
4. 寄りの画像を自分の目で見て、数値と合っているか、意図した重なりが混ざっていないかを確かめる。
5. 提案・画像・限界をユーザーへ示す。`reroute_or_cut` と見せ場の房は、ユーザーの判断を待つ。
6. 直した版を別の名前で保存し、同じ `check` をもう一度実行して `compare` で前後を比べる。新しい箇所・伸びた箇所が出たら直す。
7. 最後に、同じ保存版を描画で確かめる。数値が 0 でも、形の良し悪しは別に見る（[機械検査と見た目の検品](mechanical-visual-review.md)）。

## 実行例

```sh
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python lida_penetration_check.py -- check --input model.blend --parts Hair --solid Body Head --thin Fin Chain --allow Head --report check.json --render-dir check_views

blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python lida_penetration_check.py -- advise --input model.blend --parts Hair --solid Body --report advise.json --render-dir advise_views

python lida_penetration_check.py compare --before check.json --after check_fixed.json --report compare.json
```

Blender の中から使う時は、`check(parts, solid, thin, allow, options)` と `advise(parts, solid, options)` が `(報告, 印)` を返します。シーンは変えません。`render_marks()` はカメラと印をシーンへ足すので、保存しない別プロセスでだけ使います。

## 報告の読み方

### check

- `summary.visible_spots`・`visible_curve_mm`：見える箇所の数と、見える線の合計。`by_partner` に相手ごとの内訳。
- `summary.hidden_curve_mm`：隠れた線の合計。`allowed_spots`：別枠にした箇所の数。
- `pairs`：部品と相手の組ごとの、線の長さ・中に入った点の割合・最深・多数決が割れた点の割合。
- `spots`：箇所ごとの `center`（シーンの座標）・`size_mm`・`visible_curve_mm`・`depth_mm`・`view`（よく見える向き）・`image`。
- 多数決が割れた点が 5% を超えると警告が出ます。相手に開いた縁や内側の殻がある印で、深さの数値は疑って読みます（`open_edges` に開いた辺の数）。

### advise

- `parts`：部品ごとの島の数・辺の中央値・調べた点の数・中にある面積の割合。
- `summary`：提案ごとの数。`items`：区間ごとの提案 `advice`・理由 `reason`・上の表の数値・`entry_center`・`view`・`image`。
- 画像の印の色：赤＝削除、橙＝切る、黄＝毛先を曲げる、緑＝押し出す、紫＝通し直す／切る。

### compare

- `changes`：`new`（新しく出た）・`worse`（見える線が 5mm より伸びた）・`same`・`better`・`gone`（消えた）。
- 新しい見える箇所か伸びた箇所があると、終了コードが 2 になります。

### 終了コード

| 値 | 意味 |
| --- | --- |
| 0 | 見つからなかった（compare では、悪くなった所がない） |
| 2 | 見つかった、または警告がある。報告を読んで判断する |
| 1 | 入力・出力・実行の誤り。報告の JSON に理由が入る |

## 主なオプション

| オプション | 既定 | 働き |
| --- | --- | --- |
| `--tolerance-mm` | 0.5 | これより深く入った点を「中」と数える |
| `--cluster-mm` | 8 | これより近い線を 1 つの箇所にまとめる |
| `--view-directions` | 48 | 見えるかを調べる方向の数 |
| `--seen-directions` | 2 | この数以上の方向から見えたら「見える」 |
| `--vote-directions` | 11 | 中か外かの多数決に使う光線の数 |
| `--levels` | 2 | `advise` で面を分ける回数（1 回で 4 倍。モデルは変えない） |
| `--frame` | 保存時のコマ | 調べるコマ。揺れやポーズを焼いた動きの途中を調べる |
| `--top` | 24 | 寄りの画像を描く数 |

調べる形は、モディファイアとポーズを適用した後の形です。画面で隠していても、レンダーで表示される物体は「隠す物」として数えます。

## AI への依頼文の例

```text
保存済みの <版> を読むだけで、髪 <名前> と、体 <名前>・飾り <名前> の貫通を lida_penetration_check.py の check と advise で調べてください。
- 頭は髪の根元なので --allow にしてください。
- 姿勢は <基準の姿勢／コマ番号>。
- 報告と寄りの画像は <新しいフォルダ> へ。入力は保存しないでください。
- 結果は、相手ごとの見える箇所の数、提案ごとの数、画像を見て数値と合わなかった所、限界を分けて報告してください。
- 「通し直す／切る」と、顔のまわりの房は、直す前に私へ確認してください。
- 直した後は同じ check を実行して compare で前後を比べ、新しく出た所がないことを確かめてください。
```

## 確認済みの範囲

- Blender 5.3.0 の背景実行で、別の新規キャラクター制作の保存済みファイル（T ポーズ、骨なし）の写しを読むだけで試した。髪 2 物体（約 9 千頂点）と、閉じた相手 3・薄い相手 15 の `check` が約 5 秒、`advise` が約 9 秒。入力の SHA256 は実行の前後で同じ。
- `check` は頭を別枠にして見える箇所 46、見える線の合計 約 2.5m。寄りの画像で、房が体へ入って消える所、毛先がひれを突き抜ける所、肌の上の小片が印と合うことを確かめた。
- `advise` は体と尾で 18 区間：通し直す／切る 6、切る 6、毛先を曲げる 2、押し出す 3、そのまま 1。画像で入口の位置を確かめた。
- 通常 Python のテストで、交わる線の長さ、箇所のまとめ、提案の条件、しきい値の変更、前後の比較、既存出力の保護を確かめている。

未確認：提案どおりに直した結果、ほかの Blender 版、骨とポーズのあるモデル、動きの途中のコマ、深さの数値の個別の確かめ、薄い相手の直し方の判定、使用先での見え方。作例の数を品質の基準にしません。
