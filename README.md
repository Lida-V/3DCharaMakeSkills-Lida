# 3DCharaMakeSkills-Lida

画像から3Dキャラクターを作るときの、素材・調整方法・AIへの指示をまとめた制作ノウハウです。リダの制作で繰り返し直した点を、次の制作で使える手順へ整理しています。

**非公開の開発版 `0.1.0-dev`。キャラクターと記事は制作途中です。** 元モデルや完成アバターの配布物ではありません。検証途中の方法はその範囲を明記し、具体的な寸法・本数を他のモデルの既定値にしません。

## 最初に読む

[工程索引](skills/lida-avatar-workflow/references/process-index.md)から、必要な工程だけ読みます。

| 工程 | 素材と確認すること |
|---|---|
| 素材をそろえる | 同じキャラ・縮尺・表情の原画、素体、服、上着、角度別資料 |
| 通常形を決める | 正面/横/斜めの形と接続を確認してから表情と精細仕上げへ |
| 動きを整える | 骨の中心/軸、曲がる帯、輪、重みを対応させて途中動作も確認 |
| 失敗を直す | 形・網目・骨・重み・陰影を分け、大きい破綻から直す |
| 一つへまとめる | 部位差分と骨/爪/服の版をそろえ、全身動作と出力先で確認 |

顔・衣装などリダ固有の好みは[短いあとがき](skills/lida-avatar-workflow/references/lida-design.md)へ分けています。

## AI向けスキル

[lida-avatar-workflow](skills/lida-avatar-workflow/SKILL.md) は知識と依頼方法のパックです。Blender、画像/3D生成サービス、接続ツール、モデルデータ、認証情報は含みません。

利用するエージェントのスキル保存先へ、`skills/lida-avatar-workflow` フォルダを**中身ごと**コピーします。参照文書と画像を残してください。Codexでは `$lida-avatar-workflow` と指定して使えます。既存の同名スキルを更新するときは、自分の変更を退避してから差し替えます。

依頼例：「このモデルの膝が曲げると潰れます。原画と通常形を保ち、骨・輪の配置・ウェイトを分けて診断し、途中姿勢も含めた比較と修正案を作ってください。」

## 更新する

[更新手順](UPDATING.md)と[変更履歴](CHANGELOG.md)に従い、制作で確認した学びを短く追加します。コミット/PRごとに自動検査し、リンク切れ・個人のローカルパス・掲載対象外の資料・認証情報の混入を止めます。検査は画像の内容を完全に判定するものではないため、新しい図版は目視でも確認します。

ローカル確認と配布用ZIPの作成（Python 3.11以上、追加ライブラリ不要）：

```sh
python scripts/validate.py
python -m unittest discover -s tests
python scripts/build_package.py
```

GitHub Actionsの「Validate distribution pack」でも同じ検査とZIP作成を行います。ZIPは実行結果のArtifactsから取得できます。公開リリース・公開範囲変更は自動で行いません。
